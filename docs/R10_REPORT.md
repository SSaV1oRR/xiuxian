## 2. 转换（工具都在 `tools/`，Blender 5.2 后台运行）

**建筑** `tools/convert_buildings.py` + `tools/prepare_building_textures.py`
1. 导出内嵌贴图；处理贴图（`prepare_building_textures.py`）：
   - 抹去招牌字（周围底色向内扩散填补）；凌云阁正面横匾重铺木纹、写「凌云阁」（楷体、旧金 #C4A05C、字口阴影）；
   - 屋瓦（黄琉璃、深灰瓦）统一为青灰：暗部 #354957、亮部趋中性灰，保留瓦垄、瓦当明暗与纹样；
   - 朱红木：橙红偏向正红、略提亮（#7E342D 方向），木纹、描金不动；
   - 004 与 003、021 与 015 是同一张图（逐像素差 ≤ 7）合并；各栋共用的门窗木作图集 003 保留 2048，其余 1024。
2. 合并、缩到米、删地砖（贴地的扁平面片）、删招牌：五处立牌连同立柱底座整件删除，律师招牌对象删除；D 院中八只木箱、A 院角招牌小檐按位置剔除；Et 按塔身各层外缘（台基、墙身、腰檐、平座、顶檐）裁掉门楼的长木刺、院墙与铺地。
3. 各栋居中、H 与 X 转 -90°（使主入口朝游戏 +Z）、底面落到 0，材质金属度 0、粗糙度 0.82；导出 `assets/converted/buildings/buildings.glb`（9.3 MB，8 个节点、16 张贴图）。
4. 碰撞网格（0.5 米一格，写进 `buildings.json`）：每格自上而下取全部交点 → 可站面（近水平、上方净空 ≥ 1.9 米）；从外圈地面逐格扩展（每步高差 ≤ 0.45 米、两格之间身高范围内无构件），只有走得到的面才算可走（踏道逐级可上，台基侧壁上不去，楼上平座走不到）；走得到的格若在 0.7 / 1.1 / 1.5 米处 0.2 米内有构件即为阻挡，再按 2.2 / 3.0 米处有无构件分“矮挡”（栏杆）与“高挡”（墙、柱、门扇）。

## 4. 山体、崖壁与台地衔接

**先大轮廓**（`terrain.js`、`layout.js`）
- 西涧：峡谷源头飞瀑以下整条深涧下切约 20 米，飞瀑落差 18 → 33 米；山门石桥下的涧水 -12.9 → -34.5 米。
- 东谷：谷底 -2 ～ -21 → -2 ～ -54 米。
- 五区台地下的谷地：西谷 -2 ～ -12 → -11 ～ -34 米，东谷 -4 ～ -21 → -26 ～ -52 米；台沿到谷底 40–70 米。
- 外谷：东谷以东、西涧以西、山门石桥以南三面地面整体下落到约 -40 ～ -50 米（谷缘按低频噪声扭曲，不出直线），西岸竹林台、古碑、寒玉台、后山一带不动；两侧近山脊顶 62 → 88 米上下，岩脊起伏加大，脊上石峰 6 → 8 座、加高。
- 山门石道：石桥以南成一道山脊，脊背 10 ± 3.5 米宽，两侧先约 60° 陡落、再约 1:1.3 岩坡落到谷底；两侧前景石峰（-36, 166）、（40, 186）由谷底拔起 26–30 米。
- 云海、谷中薄雾随谷底下移 15–20 米（只调高度，未增加效果）。

**再大岩体**（`src/world/crags.js`，扫描岩壁实例化 547 块）
- 台地绝壁 70 块：沿五区崖线每隔约 0.55–0.75 块岩宽一块（左右搭接），顶端压在崖口下 1.5–4 米；高崖分上下两层；崖脚压半埋的大落石。
- 外谷谷壁、深涧两岸、山脊崖面 477 块：按地形检出陡壁（坡度 > 48°、上下坡 12 米落差 > 10 米；台地填方一侧的护坡 37° 起），落差大的先放、按三维间距（同一面高崖可上下叠放）；岩面顺坡朝外、按坡度后仰；大小随落差（缩放 1.2–7，岩块高 13–74 米），顶端不高过上坡地面 2 米、不高过附近台地 / 龙台 / 建筑地面 2 米；道路、台阶、桥、瀑布、水面一带留空。
- 每块：进深压扁到 0.55、约三分之一用壳的背面（外凸的岩肩）、偏航与后仰随机、明度 ±6% 随机。
- 四级细节按“距离 / 缩放”切换（10 / 32 / 80，流畅 ×0.6、精美 ×1.3），150 米分区合批（20 区、每区每级一次绘制）；阴影用 1,629 面一级的代理。
- 碰撞：岩块绝大多数在角色走不上去的陡坡上；伸进可走地面（坡度 < 46°）的 107 块按岩块朝向各加一个不挡镜头的长方体。
- 程序化崖壁（`cliffs.js`）与地形陡坡的岩面改用扫描岩壁烘焙的四方连续贴图（7.5 米一幅），另取 1.63 倍尺度的错位一层按大尺度噪声成片替换，打散重复；岩色仍按 #92968B / #606962。

**崖边**：五区台沿的挡土墙与栏杆沿用；新的石道山脊两侧沿脊背边缘加看不见的挡（不挡镜头）。从广场出发按角色的坡度规则泛洪（1.5 米格），能走到的最低点是 -3.1 米（桥头石阶下），走不进任何深谷；从石道山脊出发也出不了脊背。

## 8. 未改动的部分与必要的调整

按要求未改：树木花草、荷花、灵池、瀑布、聚灵阵、桌椅、灯笼与其他装饰物，双龙、地下秘境、战斗、修炼、任务、存档、角色控制，也没有新加视觉特效。因新建筑或新地形穿插而做的必要调整：

- 移位：竹院桂树、云顶殿后两株老松（移到两侧山肩）、殿侧两株金叶树；竹院花钵；茶桌、官帽椅、长凳、瓷瓶从旧正房前廊移到楼前院中；北舍水缸、扫帚、水桶、长凳；膳堂水缸、石灯、灶屋。
- 随旧屋撤去（原本挂在 / 摆在旧建筑的檐下、前廊上，换屋后会悬空）：旧正房前廊竹帘、旧膳堂台明上的边柜瓷瓶竹帘、问道殿抱厦与前檐宫灯、凌云阁前廊宫灯、丹殿前廊宫灯与药束。
- 跟随新地形自动变化：西涧源头飞瀑变长（落差 18 → 33 米）、溪流与水雾跟着下移；云海与谷雾下移。

## 9. 仍有的限制

- **建筑素材的画风**：01.fbx 是游戏用的手绘贴图模型，明暗烘焙在贴图里，没有法线、粗糙度贴图；檐角、脊饰是夸张的卷角样式。本轮统一了瓦色与红色、抹去招牌字，但贴图里烘焙的阴影方向与场景日光不一定一致；近看贴图分辨率（1024，门窗图集 2048）不如程序化构件锐利。
- **建筑素材授权**：01.fbx 由项目作者提供（3d66 模型网导出，文件内无授权说明），公开发布前请核对授权。
- **室内**：新建筑的室内是贴图壳，不能进入（碰撞按实心处理）；问道殿、膳堂、寝舍仍是原来的文字内景面板，丹殿进门仍进入原丹房场景。
- **岩体重复**：扫描岩壁只有一块 10 米岩面。翻面、压扁、大小与明度随机后，两块大岩体并排近看时仍能认出同一岩形。
- **岩体碰撞是近似的**：只给伸进可走地面的岩块加了朝向长方体，岩面的凹凸不精确。
- **性能**：接引院、前庭视点比第九轮多 1–2.5 ms；贴图显存多约 140 MB。
- **山门石桥**：桥身是程序化拱桥，拱跨按新涧宽放大，但桥墩是直接砌到岩坡上的实体轮廓，不是独立墩柱。
