# 第十六轮：通天塔第五十层 · 镇塔龙君·烬霄

本轮把 `Dragon Character 3d by Oscar Creativo.fbx` 做成通天塔第五十层的守关首领「镇塔龙君·烬霄」，完成一场可以实际挑战的完整战斗。只做了第五十层。沿用现有的引擎、角色控制、出剑、格挡、闪身、剑诀、伤害结算与存档。

本轮包括：
- 素材核对与转换；
- 龙的骨骼动作（编排 33 段）；
- 第五十层「镇龙封印殿」场地与入口；
- 十二招（各有动作、判定、预警、特效、调息、AI 条件）；
- 两阶段的气血、速度与反应；
- 受击三档、架势、AI；
- 三维特效与程序合成音效；
- 四段可跳过的过场；
- 结算、存档、重试、退出与清理；
- 调试入口；
- 实际运行的录像与连续截图。

几点约定：
- **原始素材只读不改**。FBX 原件留在 `assets/boss/boss50/source/`，转换结果写在 `assets/converted/boss50/`，转换脚本在 `tools/`。
- 改动前的项目备份在 `backups/xiuxian-r15-20261009-0239.zip`。
- 下文的数字都是从文件里读出来、或在游戏里实测的。

## 1. 素材核对

### 1.1 原始文件

`assets/boss/boss50/source/Dragon Character 3d by Oscar Creativo.fbx`（11.6 MB），逐项读文件核对：

| 项目 | 实情 |
|---|---|
| 骨骼 | 99 根（Auto-Rig Pro 式命名：`root_x`、`spine_01–03_x`、`neck_x`、`head_x`、`c_tail_00–06_x`、两臂、两腿、手指、翼） |
| 网格 / 材质 | 15 个网格、15 个材质 `DRAGO_<格>`，各自的 UV 恰好落在一个 UDIM 格（1001–1043） |
| 三角形 | 167,300 |
| 动作 | 1 段 `3677379169280_TempMotion`，21.1 秒（30 帧/秒） |
| 贴图 | 引用 45 张外部贴图，**没有内嵌**；引用的文件名（`DRAGO_<格>_Diffuse/Metallic/Normal`）**一张都不存在** |
| 单位 | 厘米（Armature 节点缩放 0.01） |

### 1.2 贴图：缺什么、怎么补

`assets/boss/boss50/textures/` 里有 62 张 4096² 的贴图，命名是 `DRAGON_BAJA_BAJA5_<类>.<格>.jpg`：

| 类 | 数量 | 说明 |
|---|---|---|
| BaseColor | 15 | 对应 FBX 引用的 Diffuse |
| Metallic | 15 | 对应 FBX 引用的 Metallic |
| Normal | 15 | 对应 FBX 引用的 Normal |
| Roughness | 14 | FBX 没引用。**缺 1043**（右翼上段） |
| Emissive | 3 | FBX 没引用。只有 1003（两只眼）、1031、1041（胸前细纹）三格 |

处理方式：
- **按格号逐一对上**：FBX 引用的 45 张全部由同格号的贴图代替。
- **补 Roughness.1043**：不能借 1042 的，两格 UV 摆法不同，底色逐像素平均差 36/255。改用另外三格翼膜（1042、1012、1013）上拟合的「底色亮度 → 粗糙度」关系，由 1043 自己的底色推出。这一张是**合成的**，不是原作者画的。
- **没有的贴图**：没有 AO、高度、透明遮罩。自发光只有眼睛与胸前细纹三处。所以二阶段的「发光裂纹」不是手绘贴图，而是着色器在体表按噪声等值线生成的（见 §8）。

### 1.3 骨骼与部位

按实际形体核对过各部位对应的骨：

| 部位 | 骨 |
|---|---|
| 躯干 | `root_x` → `spine_01_x` → `spine_02_x` → `spine_03_x`；胸骨 `c_breast_01/02_l/r` |
| 头 | `neck_x` → `head_x`。**没有下颌骨**：嘴不能张开 |
| 双臂 | `shoulder_l/r` → `arm_stretch` → `forearm_stretch` → `hand`，另有扭转骨；四指三节加拇指（`index/middle/ring/pinky1–3`、`thumb1–3`） |
| 双腿 | `thigh_stretch` → `leg_stretch` → `foot` → `toes_01`，另有扭转骨 |
| 尾 | `c_tail_00_x` … `c_tail_06_x`，7 节 |
| 双翼 | `shoulder_dupli_001_l/r` → `arm_stretch_dupli` → `forearm_stretch_dupli` → `hand_dupli`，带三根羽骨 |

双翼原本挂在 `root` 上，与身体脱节：身体弯腰时翼留在原地，被拉长。转换时改挂到 `spine_03_x`（胸背），TempMotion 的翼轨道按改挂后的父骨重算。原模型的外形特征（双翼、角、尾、爪、胸前金甲）都保留。

### 1.4 原动作 TempMotion 里实际有什么

按 0.5 秒逐帧取样：骨盆高、头相对骨盆的朝向、翼尖间距与高度、尾尖位置、两手间距。

| 时段 | 内容 |
|---|---|
| 0–7.5 秒 | 直立站姿；头左右转动张望；翼几次扬起、收拢；尾小幅摆动 |
| 8–12 秒 | 压低重心的戒备站姿（骨盆降约 9 厘米、两手分开）；头左右摆 |
| 12.5–14.5 秒 | 回到直立；翼收在背后 |
| 15–21 秒 | 再次压低戒备；张望、甩尾 |

结论：**原地的展示 / 待机动作**。没有行走、攻击、受击、失衡、倒地。游戏里取其中几帧作底姿势与翼的预设：
- 9.3 秒：正面戒备站姿（底姿势）；
- 14.0 秒：翼收拢；
- 8.8 秒：翼大张；
- 0.05、2.3、0.5 秒：翼上扬、半张、全展。

### 1.5 转换与优化

```
assets/boss/boss50/source/*.fbx（只读）
  └ tools/boss50_textures.py   15 格拼 4×4 贴图集（每格留边距、边缘填色）；底色 4096 / 2048，法线与 ORM 2048 / 1024
  └ tools/boss50_blender.py    Blender 后台：导入 FBX，UDIM → 贴图集重排 UV，15 网格合 1、15 材质合 1，导出 tools/_build/boss50_base.glb
  └ tools/convert_boss50.py    翼改挂、动作重定向（见 §2.3）、写 boss50_full / boss50_lo
  └ tools/convert_boss50.mjs   gltf-transform：去重、焊接、重采样、减面、量化、meshopt 压缩
     → assets/converted/boss50/boss50.glb    9.4 MB：167,300 面、98,524 顶点；底色 4096，法线、ORM 2048
     → assets/converted/boss50/boss50_lo.glb 3.6 MB： 75,285 面、48,130 顶点；底色 2048，法线、ORM 1024（流畅画质）
```

- **主要靠贴图尺寸、材质合并与 LOD**：均衡、精美画质用全面数（近看的轮廓、脸、爪、尾的细节都在）；流畅画质用减面版。
- 骨骼、蒙皮、动作、材质分层都保留。
- ORM 贴图：R = 自发光遮罩，G = 粗糙度，B = 金属度。
- 加载用 `GLTFLoader` + `MeshoptDecoder`（`vendor/addons/libs/meshopt_decoder.module.js`，MIT，见同目录 `MESHOPT_LICENSE.md`）。
- 模板只载入一次。编排动作在载入时生成，约 0.2–0.3 秒。离开第五十层时放掉显存，下次进场重新上传。

### 1.6 每场一只独立的龙

`Boss50Rig`（`src/actors/boss50.js`）用 `SkeletonUtils.clone` 克隆，自有：
- 骨骼、材质（克隆后改着色器）、`AnimationMixer`；
- 气血、架势、AI、特效、点光源池。

它不进 `combat.enemies`，也不进护宗双龙的目标列表（双龙只在宗门地表找魔修），与双龙不共用任何战斗状态。

## 2. 动作

### 2.1 编排动作（真实的骨骼关键帧）

`src/actors/boss50Pose.js` 是姿势编排核心，在骨架空间按关键姿势解骨骼：
- 躯干、颈、头：按骨架轴转；
- 双臂、双腿：两节 IK 带肘、膝朝向；
- 爪：按掌面法线弯曲四指；
- 尾：yaw / lift / curl / wave 沿 7 节分配；
- 翼：TempMotion 预设混合；
- 根运动：地面位移与转身，脚以地面为参照，踏步时不滑。

`src/actors/boss50Clips.js` 用它生成 33 段动作，每 1/30 秒取样解一次 IK，写成四元数轨道。

**攻击都有前摇、发力、接触、收势**，是身体真的在动：
- 爪击：腰身扭转、前屈、踏进，爪尖在接触时落到 1.3–1.8 米高，正好是人的胸腹高度。2.8 倍的龙原本的爪击在玩家头顶 1 米处挥过，所以把出手姿势改低了。
- 尾扫：转身一周；冲撞、跃击：由游戏推着走。
- **没有一招是整体旋转模型**。

做过的自检：
- 逐段扫过所有骨的世界高度，**没有关节入地**（膝、趾、尾尖、爪尖在跪地、倒地、处决姿势里都在地面以上）；
- 按根运动逐 0.01 秒量出各爪击爪尖实际扫过的角度与高度，用来定扇形判定（见 §5）。

### 2.2 运行时叠加的层

| 层 | 作用 |
|---|---|
| 尾巴缓摆 | 沿 7 节传的正弦（权重随状态变，倒地后渐停） |
| 头颈看向玩家 | 限角：左右 ±40°，俯仰 −10°～+32°；出招时权重降低 |
| 轻受击 | 上身弹簧式后仰、向受击一侧扭。一阶段约 0.3 秒，二阶段弹簧更硬，约 0.18 秒 |
| 蓄力光 | 双爪、胸口附近的能量脉络（世界距离衰减 × 噪声等值线） |

### 2.3 重定向动作（打包了，但最终的战斗没有用）

`tools/convert_boss50.py` 用对齐旋转法把 32 段人形动作重定向到龙的躯干、头、双臂、双腿上，尾、翼、指取戒备站姿。来源：
- Quaternius Universal Animation Library 2（CC0）24 段；
- 金白修士素材自带的 Mixamo 动作 8 段。

这些动作打包在 glb 里（`u_*`、`m_*`）。评估后，十二招与各状态最终都改用 §2.1 的编排动作：龙的体型、尾与翼是人形动作没有的，编排的更贴合。它们保留在文件里作参考与回退，**运行时不播放**。

### 2.4 没有、补不了的

- **没有下颌骨**：嘴不能张开。吐息、怒吼、处决的蓄息靠昂头、俯首、胸口蓄光、嘴部挂点的特效与音效表现。
- 没有面部表情骨、眼睑骨：「二阶段变眼」做在材质上（发光遮罩转亮、色相变紫）。

## 3. 第五十层：镇龙封印殿

`src/world/tower50.js`，独立场景（同一层接引大厅），第一次进入时搭建，约 6 万面。

| 位置 | 数值 |
|---|---|
| 战斗圈 | 半径 25 米（直径 50 米）。开战后圈沿升起半透明的封印光墙，玩家与龙都出不去。龙心不出 23 米，身体不碰墙 |
| 外圈 25–33 米 | 十二根巨柱（直径 2.6 米、没入殿顶云雾，三根已断、断口与碎石堆在柱脚）、六块倾倒的残破石台、碎石。**全在战斗圈之外**，不挡出招前摇，也不挡镜头 |
| 北面封印台（圈外） | 八角台，高 2.2 米，四角镇柱牵着四串锁链到两侧柱子。龙君在台上跪伏沉睡（未触发） |
| 南面 | 拱门与一段甬道。进殿处 (0, 31.5)，面朝北 |
| 四周 | 二十四边形高墙（半径 35 米、高 24 米），以上全是云雾；圈外贴地薄雾 |

关键站位：
- 玩家进入点：南门内 (0, 31.5)；
- 龙的出场点：封印台 (0, 2.2, −29.2)；
- 落地点：(0, −14)；
- 失败复位点：圈内南侧 (0, 19)；
- 触发圈：半径 23.5 米。

**地面**：圆形条石地（Poly Haven paving 贴图），刻着封印大阵：
- 内容：圈沿双线、八卦、三十二个镇龙符字的符文带、八道放射符线、正中「镇」字与螺旋。
- 画法：画布贴图三个通道——R 刻线压暗、G 符线发光、B 裂纹。
- 动态：
  - 出场时封印纹自玩家脚下向外亮开；
  - 灭世龙怒蓄力时整圈渐亮；
  - 落雷、冲击时闪一下；
  - 二阶段沿裂纹透出紫焰。

**配色**：
- 龙身是局部着色，不整片盖色：暗鳞偏 #252830，金属甲片偏旧金 #B88A46。
- 发光遮罩（眼、胸前符纹）：一阶段 #7C68E8，二阶段 #B65CFF，芯 #EEE5FF。
- 殿内补光偏中性，紫色只留在封印台、战斗圈的点光与符纹上。

**入口**：
- 塔里还没有逐层通关的规矩（二至四十九层尚未制作）。第一版在一层的**楼层传送阵**上开放第 50 层（`towerSpec.js` 的 `TOWER_FLOORS`，名册上亮紫色、标「守关」）。
- 点第 50 层 → 挑战说明（两阶段、预警颜色、架势、注意事项、通关记录）→「进入第五十层」。
- 守塔执事的对话、百层碑的描述随之更新。其余楼层不变，仍是「尚未开放」。

**御剑**：只在宗门地表可用（原有规则）。第五十层里按 F 提示「封印殿中灵压沉重，御剑之术施展不出」，回到宗门自会复原。

## 4. 流程与状态

```
未触发（龙在台上沉睡；可走动、可从南门 E 离开）
  → 踏入封印阵 → 出场过场 A
  → 一阶段 → 一阶段气血耗尽 → 阶段转换过场 B → 准备 1.2 秒 → 二阶段
  → 二阶段气血耗尽 → 击败过场 C（奖励入账）→ 结算：再战 / 返回塔中
玩家气血耗尽 → 失败处决过场 D → 失败界面：重试 / 返回塔中
战斗中按 X → 放弃挑战（确认后复原到未触发，站到南门内）
```

**龙的状态**：
- dormant 沉睡、cine 过场；
- idle 待机、walk 行走、turn 原地转身；
- move 出招：前摇 → 出手 → 收势；
- hitH 重受击、stagger 失衡（踉跄 → 跪地 → 起身）；
- 死亡见过场 C。

**出招规则**：
- 每一招都有前摇、出手、收势；
- **只在出手窗口里判定**；
- 同一下只结算一次；持续伤害有自己的间隔（龙焰 0.35 秒一跳）；
- 追踪到前摇的某一刻为止，之后方向锁定；收势末尾不突然转身。

**场地**：龙被限制在圈内，不穿墙、不穿柱（柱子都在圈外，龙心不出 23 米），不瞬移追身。

**操作**：沿用原有的左键出剑、右键格挡、移动鼠标转镜头、C 闪身、Q R T V 剑诀、G 服丹。

## 5. 十二招

角度相对龙的朝向，**向龙的左手边为正**。距离为米，时间为动作的 clip 秒。

**判定与预警用同一组数**：
- 扇形以「出手那一刻的站位」为心，前摇里预警跟着龙走，出手时定住；
- 爪 / 尾按爪尖、尾尖**这一帧实际扫过的角度**是否经过玩家来判定，并夹在预警扇形之内；
- 圆、环、路径、锥同样以预警边为界，只放宽 0.2–0.25 米作玩家身体。

## 7. 受击、架势与 AI

**龙受击分三档**：
- **轻**：局部后仰（弹簧层）、火花、材质轻微闪一下，不打断。
- **重**（破岳、流云第三式、万剑归宗末式、弹反之类）：
  - 打在可打断招式的前摇里，或龙在待机、走路时：放 hitH 后仰退步。每 3.2 秒（二阶段 4.5 秒）最多一次，不能用重击连锁硬直。
  - 其余情况：较大的后仰。
- **失衡**：架势满了，踉跄 → 单膝跪地、右爪撑地 → 起身。期间受到的伤害 ×1.3。龙首低于 2.9 米时打中头颈算「要害」：伤害 ×1.2、架势 ×1.6。

**架势（0–100）**：
- 累积：寻常命中 +3.4，重击 +7，要害 ×1.6，弹反 +22（二阶段 +18），灭世龙怒蓄力中 ×1.6。
- 最后一次累积后 2.4 秒开始回落，每秒 10（二阶段 8）。
- 失衡结束后清零，并有 4.5 秒保护期不再累积，不能无限连续失衡。
- 冲刺中、空中失衡：等刹停 / 落地后才跪下。

**玩家受击反应**（`moves.react`，按来袭方向）：

| 来源 | 反应 |
|---|---|
| 爪 | 轻后仰（约 0.36 秒，0.12 秒后可闪身） |
| 砸地、冲撞、尾扫 | 重击退（踉跄后退 3.5 米） |
| 跃击、三段猎杀的重砸 | 短暂击倒（倒地起身，期间无敌） |
| 雷击 | 短暂麻痹（0.85 秒，身上电光） |
| 被破防 | 剑被震开、1 秒内举不起剑 |

- **受击连锁保护**：龙的寻常命中后无敌 0.22 秒（两爪、三段之间相隔 0.33 秒以上，每一下都单独结算）；3.5 秒内第三次被打中，给 1.3 秒护体。
- 守关战中**停止寻常的气血回复**（服丹照常），灵力按交战回复。

**AI**：
- 按距离分近（< 6.5 米）、中（6.5–13 米）、远（> 13 米），另判「玩家在身后」。
- 每招在各区有权重（见上表）；正面招式遇玩家在身后时降权，尾扫在身后时权重 6。
- 二阶段加入焚灵囚阵与灭世龙怒（灭世龙怒两次间隔 ≥ 14 秒）。
- 降权：刚用过的招 ×0.1，最近三招 ×0.55。调息中的招不选。
- 选中的招要先走近（最多 4.5 秒）、先转身（正面招式），再出手。
- 两招之间留空隙，大招之后再多 0.4 秒。
- 空隙里远了慢慢逼近，近了原地转向。

一场自动对战（两个阶段合计）里各招被选中的次数：01 ×6、02 ×9、03 ×4、04 ×1、05 ×3、06 ×3、07 ×3、08 ×1、09 ×3、10 ×3、11 ×2、12 ×1。十二招都用到了。

## 9. 四段过场

`src/game/boss50Cine.js`。每段由镜头段、事件与 finish 组成。镜头段可随骨骼移动，两段之间即切镜。finish 在结束**或跳过**时一律执行，把龙、场地、玩家摆到应有的结束状态，可重复执行。

## 10. 操作、存档、结算

- **过场中**暂停一切寻常输入。残留的危险物在转阶段、击败、处决开始时清掉；过场中双方都不受伤。
- **唯一处理**：一阶段耗尽、二阶段耗尽、玩家力竭、退出各有一个只走一次的入口（标志位守着）。
- **只有二阶段耗尽才算通关**；一阶段没有通关奖励。
- **奖励只发一次**：灵珠飞入时入账，过场被跳过时由 finish 补发；重复点击结算按钮不会重复领取。
  - 首通：宗门贡献 +120、镇塔龙印 ×1、烬霄龙鳞 ×2、养元丹 ×3；
  - 之后每次：宗门贡献 +20、烬霄龙鳞 ×1。
- **存档**（`qinglan.save.v1` 的 `tower50`）：通关次数、最佳用时、首通时间、首通奖励是否已领、挑战次数。
- **用过调试入口**的一场：不计入记录、不发奖励，结算里会写明。
- **结算**：用时（与最佳）、承受伤害与被打中次数、造成伤害、格挡 / 弹反 / 闪身次数、使其失衡次数、奖励。
- **失败界面**：坚持时间与龙君余下气血、同样的统计、提示。
- **重试**：两个阶段、气血、架势、调息、招式历史、场地（封印、光墙、南门、锁链、裂纹、地面光）、伤害统计、玩家气血灵力与剑诀调息全部复原。龙回到封印台，玩家站在复位点，随即再次开场（可跳过）。关掉失败界面则站到南门内，不自动再开战。
- **退出**（结算的「返回塔中」或南门内按 E）：
  - 拆掉龙（材质、骨骼、动作缓存）、特效、预警、危险物、点光、界面、监听、战斗目标、音效持续音；
  - 关掉守关标志（气血回复、交战状态）；
  - 恢复镜头、输入；
  - 放掉模板显存。
  - 回到一层楼层传送阵前。御剑回到宗门地表即可用。

### 12.4 自动对战与平衡

`bot()` 是一个照规矩打的玩家：
- 只用键位（`input.keys`）、剑诀入口、右键格挡；
- 红圈往外走，快落下时闪身；可格挡的举剑，偶尔掐准弹反；收势与失衡时进攻；气血低时服丹。

调低伤害约 15% 后的 12 场：

| 机器人技巧 | 场数 | 结果 |
|---|---|---|
| 1.4 | 5 | 胜 1（148 秒） |
| 1.0 | 2 | 都败 |
| 1.8 | 5 | 胜 2（156.6、184.4 秒） |

- 一阶段用时 79–177 秒；每场都打进了二阶段。
- 败局时龙君余下 116–1078/1300。
- 一场里被打中 26–41 次，五枚丹药基本用完。

结论：难而可胜。真人能用闪身无敌躲过红圈，比机器人强。数值都集中在 `CONFIG50` 与 `MOVES50`，可再按真人试玩调整。

**修掉的问题**：
- 失衡中每一下都重新失衡：第一场对战失衡了 39 次，已修；
- 0.5 秒受击无敌吃掉了两爪、三段的第二下：改为龙的寻常命中只给 0.22 秒，另加连续受击护体；
- 龙焰方向偏了 30°：原来取头骨到嘴的向量，改为龙身朝向、自嘴部发出；
- 处决时爪够不到地：重做按住姿势；
- 跪地、倒地姿势里尾与膝入地：调抬尾、改膝的朝向与骨盆高度；
- 镜头钻进巨柱、石台：镜头限制加柱、石台、封印台；随龙、随玩家的过场机位不出圈；
- 受击闪光把整只龙照白、焰柱成一块亮块、冲击光晕盖住龙、二阶段地面过亮：都已压低；
- 冲撞路径、冲击环外缘、吐息射程的判定比预警宽：已与预警边对齐；
- 灵弹弹道预警用的是现实时间计时：改为游戏时间。

## 14. 未解决的问题与限制

1. **没有下颌骨**：龙不能张嘴。吐息、怒吼靠头颈动作、蓄光、特效与音效表现。
2. **Roughness.1043 是合成的**（见 §1.2）。自发光只有眼睛与胸前细纹三格；二阶段裂纹是程序生成的，不是手绘。
3. **重定向的 32 段动作**打包在 glb 里但运行时不用（见 §2.3），可以从文件里去掉省一点体积。
4. **LOD 按画质档选一套**（均衡、精美 16.7 万面；流畅 7.5 万面），没有按距离切换。
5. **数值只对规则机器人调过**（12 场 3 胜），还需要真人试玩再调。
6. **龙尾回扫是整圈**：转身一周，正面也会扫到，不只身后与两侧。预警是整圈环形，与判定一致。
7. 处决是按住版。玩家的挣扎由受击、起身两段动作的片段拼成，没有专门的挣扎动作。
8. 镜头离焰柱很近（钻进柱里）时，加色叠层会成一片亮紫，持续不到一秒。
9. 原 FBX 的作者署名为 Oscar Creativo，素材由项目作者提供。素材目录里没有授权文件，**请确认使用授权**。
10. 二阶段地面裂纹与符纹较亮，画面偏紫。这是有意的「龙怒」氛围，可在 `tower50.js` 的地面着色器里调低。
