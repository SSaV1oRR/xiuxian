## 1. 各区域改了什么

### 地形与基础（五区共用）
- **崖壁**（`cliffs.js`）：岩面轮廓改为“大块岩体 + 块状节理面 + 少量深裂隙”，去掉第八轮的规则竖向岩柱、层层薄岩檐和均匀碎石；每一列岩面向下内凹不超过 0.4 米/米（不出现悬空的薄片）；崖脚碎石成组（每 35–60 米一组 3–5 块），岩台上只在朝上的面长灌木与小松；苔藓只在湿阴的裂隙与落水槽。
- 去掉 `layout.js` 里 P1–P4 四根圆柱形岩台、谷底的碎石纹路与谷中樱花林。
- **光照**：日光略暖、强度 3.0 → 2.75；白天柔光门槛 0.74 → 0.88（受光的白石铺地不再整片泛白）；天光略降、减蓝。铺地的暖白石基色按 #D8D5C9 起步、板与板之间有色差。
- **镜头**：撞地时改为沿视线方向缩短距离，不再把镜头抬高——走动中俯仰不会被改成俯视；鼠标单次异常大位移（失焦、回绕）丢弃。

### A 山门
- 阙楼上层改成真正的楼层：柱网、楼板、天花与楞木、正面两间各四扇隔扇门（中间两扇向内开着）、两山各一扇支摘窗撑起、背面槛窗；室内有吊灯、条案（香炉、书匣）与圆凳。
- 门楼明间两扇板门向内开启，门洞贯通（实测可从桥头走到接引院）。
- 柱础换成 D02-03（八角础座、青玉嵌板、覆盆莲瓣、古铜莲瓣箍）；石栏杆换成 D02-01；石狮只取扫描模型的狮身（原件下部是石柱），放在 D02-04 式须弥座上（莲瓣带、束腰青玉雕板）。
- 屋面：戗脊、垂脊沿曲面走；檐口逐垄瓦当；鸱吻鎏金。阙楼垂幡改青玉色。
- 门楼两侧樱花与银杏成组（前庭外沿与阙楼外侧台地各一组；有一株银杏因树冠会碰到阙楼，被植树程序自动跳过），门洞中线 ±10 米内不植树，保持门洞视线。

### B 演武广场与凌云阁
- 拆掉抬高 0.45 米的演武台、四向踏步、外圈金环、四角灵泉与导流槽、十二个蒲团；聚灵阵改为与铺地齐平的镶嵌阵面（D08-01/02，阵径 16 米，外接放射铺石到 20.4 米）：阵心黑白石太极与铜圈阵眼、卷云浮雕环、八卦青玉环（白石开光刻卦）、二十四字篆刻符文带、八道盘旋导流槽、外圈十六格青玉开光与八个莲纹玉心节点、铜嵌线。贴图分漫反射、法线、粗糙度/金属度、发光遮罩四张；发光只在导流槽、节点和修炼时的卦、符文、阵眼。
- 广场上三位弟子与打坐点落到地面（y 14）。
- 问心阶顶新建三间通透门殿（明间歇山、次间庑殿、斗拱彩画，三间都可平地通行）与两段南廊，东西回廊在南端经南廊接到门殿；南廊在 x = ±17 开门接两条爬山廊。
- 石灯、旗杆、香炉、铜灯都在阵外（离阵心 ≥ 18 米）。凌云阁沿用第八轮的柱网、墙窗与层间结构，本轮只换了柱础与栏杆（未开门、未做室内）。

### E 西翼生活与藏经阁
- 竹院正房前廊：茶桌（D03-01，桌面厚度、腿、牙板、角牙、横枨）与青花茶具、两把官帽椅（Poly Haven 实物模型）、长凳、瓷瓶；窗间四幅竹帘半卷（D03-06）。
- 民居（`house`）改为朱红圆柱半露于粉墙、深红额枋，窗为有进深的槛窗。
- 膳堂台明两侧边柜（抽屉、对开门、铜拉手）与瓷瓶、窗前竹帘；东侧檐角一张茶座（茶桌、两只绣墩）。
- 藏经阁院：南门改为 D02-05 月洞门（净宽 2.4 米），东门同样改为月洞门（2.6 米）；藏经阁底层正门四扇隔扇门开启，门内天花、后墙与两山一排书柜（D03-05，书册、卷轴、小匣）、长案、边柜、灯；院中石桌换成 D03-04 石桌石凳。
- 原“紫色团块”树（`mJac01`）换成淡紫花树；银杏全部换成有主梢、上举主枝、扇形叶簇成团且留空的金叶树（三种轮廓）。

### F 丹殿与炼丹东院
- 正殿与耳房：墙改为暖白粉墙（暖白石墙裙），两山开槛窗；两厢制药房的后墙、山墙改为暖白墙并开窗。正殿丹房大门与室内场景尺寸不变（门 2.64 × 2.95 米）。
- D07 器物：储药柜（多宝格，三种药罐：白瓷、青瓷、褐釉）、操作台（拼板台面、石臼与杵、铜药秤、青瓷碗、铜碗、麻布）、晾晒架（A 字木架、麻绳扎结、药束、竹匾）、竹篮（Poly Haven 实物模型）；全部沿院边与廊下成组，中轴与两厢踏步留空。
- 大丹炉按 D07-01 重做：古铜炉身、旧金只在弦纹、团花、龙耳、狮首与炉盖筋上；两足在前侧、一足在后，火口居中在下部；两侧攀附的龙（龙腹旧金、背鳍、爪、龙首衔环）；炉盖一圈透气孔（孔内微亮）；烟囱自盖顶正中立起（分节、旧金箍、透孔烟帽），烟只自烟帽冒出；火光一盏点光只照火口一带。炼丹（交药）时烟量由 1.6 升到 2.4（复用原系统）。

### G 灵池与静修花园
- 池盆半轴 19.5 × 14 米（约占池台 36%）；环池通道在花坛、石灯之内净宽约 3.5–4.5 米；东缘溢流渠上加一道石板平桥，环池一圈可走通。
- 池壁、池底、压顶、水面分开：压顶约 0.6 米宽、圆角挑出、青玉嵌线；池壁水线上下一道湿痕；池底卵石贴图，近岸浅滩 0.32 米、池心 1.5 米，越深越暗越青；水面按水深混合 #8CC8BC → #417F83 与透明度，小幅波纹、菲涅尔反光（环境贴图），浅处看得见卵石与焦散；水位比压顶低 0.37 米。
- 修炼岛（D08-04）直径 7.2 米：两层石台出水、下层台壁青玉嵌板；台面为与演武场同一套的镶嵌阵面；外缘石栏杆（古铜莲苞柱头），南北桥口各留约 3 米；不加亭盖。
- 南北石桥（D08-03）：桥面高出水面 1.25 米，桥宽 2.9 米（栏杆内净宽约 2.4 米），岸侧 6 级（每级 0.167 米）、岛侧 3 级（0.193 米），弧券桥身与券脸、龙门石，桥头抱鼓石与古铜望柱头；栏杆顺踏步斜下，并与池岸栏杆在桥头接上（不留跌进池里的缺口）。
- 水链：东北假山顶岩缝出泉 → 石面短水道 → 两叠园林瀑布（落到底不散）→ 池中落点（白沫、同心涟漪、水雾）→ 东缘压顶降到水面的溢流缺口 → 石渠 → 挑出崖口的石槽与螭首 → 东崖瀑布 → 谷底落水潭。假山用崖岩材质的叠石（每块 2–4 层错开的厚岩板），苔藓与湿痕集中在落水处。
- 荷花（D04）：盛花（外、中、内三轮花瓣，黄蕊，莲蓬花心）、花苞、浮叶、立叶（叶柄连到池底）、莲蓬，七簇沿浅水岸，大部分水面留空。
- 南门的三间门楼换成通透的三间牌坊，从观云台、南岸都望得见池心岛。

## 7. 性能（实测）

**环境**：本机 Windows 11、Chrome 内核的预览浏览器；画布 1600×900、像素比 1；均衡画质；辰时 9.5（时间暂停）；各视点传送后镜头 `view(yaw, 0.1, 8)`；先空跑 30 帧，再连续 30 帧（每帧完整更新 + 渲染，末尾 `gl.finish`）取平均，每轮两遍取较好的一遍；三角形与绘制调用取单次绘制（含柔光后期）的累计。第八轮的数字是把第八轮备份放在另一个端口、同一台机器、同一次会话里用同一份脚本（`tools/perf_r9.js`）测的。同一机位多次测量相差 1–3 ms，表中取多轮中最好的一轮（第八轮 5 轮、第九轮 3 轮）。

|---|---|---|
| 接引院 gate | 7.9 ms / 4.11M / 765 | 8.5 ms / 4.66M / 778 |
| 前庭 fore | 6.7 ms / 4.17M / 813 | 7.1 ms / 4.69M / 802 |
| 演武广场 plaza | 9.6 ms / 3.72M / 647 | 9.4 ms / 4.46M / 647 |
| 藏经阁 lib | 5.4 ms / 3.39M / 536 | 7.0 ms / 4.29M / 536 |
| 竹院 dorm | 4.8 ms / 3.53M / 573 | 7.7 ms / 4.40M / 608 |
| 丹殿 alch | 8.3 ms / 3.82M / 607 | 7.9 ms / 4.61M / 616 |
| 灵池 pool | 6.0 ms / 3.25M / 457 | 6.2 ms / 4.02M / 459 |
| 云顶 summit | 4.5 ms / 2.64M / 341 | 6.6 ms / 3.10M / 348 |
| 后山 backhill | 3.7 ms / 2.97M / 315 | 6.0 ms / 3.23M / 314 |

| 项 | 第八轮 | 第九轮 |
|---|---|---|
| 载入（到“入山”可点时）资源 | 137 个、35.55 MB（glb 12.12、jpg 13.99、png 5.25、js 2.78、webp 1.43） | 149 个、37.39 MB（glb 13.84，多出的是 10 件 Poly Haven 陈设，原本进丹房才载入；js 2.86） |
| 载入各步合计 | 约 7.2 s | 约 9.9 s（营建院落 +1.9 s、合批 +0.6 s） |

| `renderer.info.memory` | 590 几何 / 140 贴图 | 587 几何 / 162 贴图 |

结论：绘制调用基本不变；三角形每个视点多 0.3–0.9M；每帧耗时有几处多 1–3 ms（藏经阁、竹院、云顶、后山），其余在测量波动内；几何显存多约 148 MB、载入多约 2.7 秒。

本轮为此做的优化（都没有降低近景）：
1. **细部构件按距离显示**：瓦当、栏杆净瓶与青玉嵌板、华板框条、柱础莲瓣、须弥座与石灯莲瓣带、器物小件进入单独的“细部”桶，合批后按镜头到所在合批块的距离显示（流畅 45 米、均衡 75 米、精美 110 米），细部不投影。加入前各近景视点三角形为 5.4–6.4M，加入并做完第 2 项后为 4.0–4.7M。
2. 瓦当当面外圈由圆环管改为环面（每枚 54 → 30 个三角）；净瓶 108 → 60 个三角；莲瓣环 360 → 300。
3. 合批缓冲的法线改为 16 位 4 分量归一化整数。第 2、3 两项合计使几何显存由 390 MB 降到 311 MB。试过把法线、顶点色改为 3 分量 16 位、建筑序号改为 8 位整数，显存可到 248 MB，但各视点每帧反而多 3–5 ms（推测是 ANGLE / D3D 后端要转换这类顶点格式），已改回。
4. 聚灵阵贴图生成去掉大画布上的逐笔裁剪、法线图按一半分辨率计算：载入时这一步由 1.04 s 降到 0.30 s。

## 9. 已完成 / 未完成

**已完成**：上面第 1 节所列；48 项中 37 项完成、4 项部分完成、7 项沿用（见第 3 节）。

**未完成或不足（原因）**
- **凌云阁**没有开门、没有室内（时间放在了五区主体与灵池上）；本轮只换了柱础与栏杆。
- **藏经阁**只有底层门内有陈设，二、三层仍是关着的槛窗。
- **水面倒影**只有环境贴图反光与菲涅尔，没有平面反射（项目的 `vendor/addons` 里没有 Reflector，需要自写反射相机与质量档；未做）。
- **水景质量档**：瀑布、透明水面没有单独的质量开关，跟随全局画质（细部距离、阴影、植被密度）。
- **D02-06 铺地青玉嵌边**、**D08-06 石碑**：函数已写好（`stone9.js` pavingBorder、stoneTablet），本轮没有放进场景。
- **D04-06 岸草**：池岸为白石压顶，没有种岸草。
- **石狮**两只是同一扫描的镜像，姿态相同（项目里没有第二个石狮模型）。
- **竹院院门**仍是普通院门，不是月洞门。
- **性能**：三角形、几何显存、载入时间都有增加（第 7 节），每帧耗时有几处多 1–3 ms。
- **NPC 走动路线**：只确认了广场三位弟子落地与对话，没有逐一走查其他弟子的行动路线。
