## 一、普攻第三式「突刺」、第四式「重劈」

### 问题

第二十三轮的普攻墨带沿剑的真实轨迹铺开。常用的镜头在人物背后，而突刺、重劈恰好都是顺着视线方向出的：突刺从背后看只剩一个点，重劈竖着劈下、侧对镜头的墨弧被淡掉（原来侧对时淡到 8%），只剩一条线。改动前的连拍（背后镜头）里，第三、四式几乎只看得见命中时的小团墨溅。

### 突刺（`inkFx.pierce`，参数 `INK.pierce` / `INK.ink3`）

剑尖刺到头的一刻（动作时刻 0.245）：

- **墨环隧道**：从剑尖起，沿刺的方向一串墨环一直排到这一式判定的外沿再往外 0.5 米（4 圈，依次晚出 0.03 秒）。从背后看是一圈圈往外推的墨浪，贴身和刺到头的敌人都套在环里。
- **太极印**：第一圈换成一面水墨太极印。印朝着刺的方向，0.42 秒里由 0.5 米旋转张开到 1.8 米再化开。阴的一半用墨色，阳的一半用纸白（70% 不透明，敌人透得出来）。
- **白光**：剑尖一团星芒与一圈白色光环；7 道细白光与一束白色刺线往前射出。
- **墨**：
  - 8 道放射的墨锋（原 14 道，太密，盖住了太极印）；
  - 一支墨枪顺着刺的方向探出；
  - 两片十字交叉的喷墨，从刺穿处朝前喷开，从侧面、上面都看得见；
  - 一条绕剑往前钻的螺旋墨带（约 1.9 圈，0.46 秒）。
- **竹叶**：被剑风带出 5 片。

### 重劈（`inkFx.cleaveSlam`，参数 `INK.cleave` / `INK.ink3`）

- **墨弧侧对镜头时不再淡掉**：原来侧对时淡到 8%，现在保留 70%，从背后看得见竖着的那一笔。
- **劈下时**：剑尖扫过之处留一串白色光晕，顺着剑势拉长。
- **劈到底（动作时刻 0.465）**：
  - 一道竖着的白光刀痕：高 3.6 米、0.24 秒，正对镜头，从哪个角度看都是竖的。刀痕后衬一小团墨，0.9 × 2.0 米、0.34 秒，很快散开。
  - 地上：
    - 一团晕墨（有太极印时淡到 55%）；
    - 顺着劈的方向裂开的一路：一道墨裂，两侧依次翻起 5 对墨锋，每对相隔 0.6 米、晚出 0.026 秒；遇到台阶、断崖就停；
    - 9 道放射的墨裂、一圈墨浪。
  - 一面太极印盖在地上：往前挪了 1.3 米，因为落点就在人脚前，从背后看会被人挡住。1.0 秒里由 1.4 米旋转张开到 4.4 米再化开，铺过敌人的脚下。
  - 第三组水墨的一片放射墨裂，震起 9 片竹叶，往上溅 14 点白光。
  - 白闪，半空一道竖着的白色月牙（剑势的残影），镜头轻震 0.14。

### 中途改掉的版本

重劈的第一版在劈到底时立起一高一排的浓墨柱（3.2 米高、0.5 秒）。连拍里从背后看，它把人和敌人都盖住了约半秒，正是要求里说的「看不清」。所以改成：竖着的只留一道白光刀痕和一小团墨，其余的墨都贴地裂开。

突刺的太极印第一版张到 2.1 米、纸白一半 92% 不透明，从背后看把敌人整个盖住。改成 1.8 米、70%。

见 `docs/media/r26_light_before.mp4` / `r26_light_after.mp4`：同一套连击，背后、侧面、0.35 倍慢放各一遍；对照图 `docs/screenshots/r26_light34_compare.jpg`（同一机位，改动前后各 4 帧）。

- **突刺**：1.1 秒、9.6 秒是突刺的太极印与墨环。

## 二、雷龙破虚：撞上之后的压迫感

伤害、目标与时长都不改，只加表现。参数 `DRAGON.quake`；画面 `thunderFx.quake / afterStrike / groundArc / unitArc`；调度 `thunderDragon.stepQuake`；声音 `audio.js` 的 `s_dragonSlam`、`s_zapTail`。

### 撞上的一刻

- **雷柱与气浪**：
  - 由雷云底同时劈下 3 道雷柱（错开 0.05 秒），落点一团电球爆闪；
  - 一圈深色气浪往外推到 11 米（0.8 秒，先快后慢），外缘一线电光，里面再一圈小的。白天白色的地面上，蓝白的光几乎看不见，深色的浪才看得见。
- **地面**：
  - 9 道放射的电裂纹（半径 5.5 米、留 2.6 秒）：前一半缝芯一线蓝白电光在闪，之后只剩焦黑的缝，渐渐淡去；
  - 地上一圈尘环，14 团尘贴地往外推；落点上方扬起一柱烟尘，从低机位、远处也看得出撞得多重；
  - 22 块碎石崩起。
- **镜头**：往下一顿（kick 0.6）；震屏由 0.35 加到 0.6，上限由 0.4 加到 0.65（再乘设置里的「震屏与闪光」）；白闪由 0.22 加到 0.38。
- **声音**：原来的爆雷采样之上叠一记合成的撞地声，并接上电弧噼啪。
  - 撞地声：一记往下沉的极低闷响（72 → 23 Hz），一声炸开的脆裂，碎石哗啦，之后低沉的滚动；
  - 电弧噼啪：1.6 秒，越来越稀，夹几声短促的电嗡。

### 之后一秒多

- **余震**：撞上之后 0.16、0.36、0.58、0.84 秒，再由雷云劈下 4 道。一半落在被撞到的敌人身上，一半落在落点四周 1.2–4.2 米。每道各一声落雷、一小下震屏（0.2）。
- **残留的电弧**：落点四周 3.6 米内贴地跳 1.6 秒，每秒由 18 道减到 3 道。
- **敌人身上的电光**：被直接撞中的缠 1.2 秒，被爆到的缠 0.7 秒，每秒 9 次两道细电弧，偶尔一团小电球，全身一闪蓝光。

## 三、第三十层 · 烬狱剑尊

### 体型：约 4 米，玩家的 2.3 倍

`BOSS30.scale` 由 0.875 改为 1.65：头盔顶由约 2.1 米到 3.96 米。玩家 1.72 米，约 2.3 倍。

**为什么选 2.3 倍**：
- 2 倍以下体型差别不够明显；
- 3 倍以上（5 米多），横斩、突刺要压的角度超过 30°，像鞠躬；在 36 米的剑台上镜头也很难同时框住人和剑尊。

**放大带来的问题**：动作包是按同身量的对手做的。放大之后，剑尖在伸得最远的一刻离地 0.9–1.8 模型米 × 1.65，横斩、突刺多半在 2.4 米左右，从玩家头顶掠过。办法是给每一击加一个俯身角度（`hits[].lean`），具体如下：
- **怎么压**：出手前 0.5 秒（动作时间）起把上身往前压，出手段里压满，打完 0.38 秒收回。压在 spine_01、spine_02 两节，腿脚不动；弹簧跟随，转轴按剑尊的左右轴（世界）换到各骨父节点的本地。
- **角度怎么来的**：用 `bladeProfile` 量出每一击出手段里握点、剑尖相对剑尊的真实轨迹，算出放大后、玩家站在 2.8 米处时剑身经过玩家的高度，取刚好落到胸口（约 1.15 米）的角度。27 击里：
  - 6 击不用压；
  - 多数 4–22°；
  - 最高的几记横扫（疾锋横斩、迟刃三绝的第二、三击）压到上限 30°。
- **调间距**：出招时根运动推剑尊往前的间距修正 `hit.gap` 由 1.15 米改为 1.5 × 体型 ≈ 2.83 米。实测发现，出招的冲步总是把剑尊推到间距修正的那一点再出剑。原来 2.17 米太近，剑身经过玩家时还在手边、偏高；巨人用长剑的远端打人，剑才落在胸口。

**实测**（`reach26`）：AI 关、无伤，玩家在 2.4 / 3.4 米两处。每套连招的每一击都碰到了玩家，剑身在玩家身体那一圈里最低扫到的高度都在 1.54 米以下（自检判据 ≤ 1.6 米）：

| 套路 | 各击剑身最低扫到（米，2.4 米 / 3.4 米） |
|---|---|
| A01 疾锋横斩 | 1.49 / 1.49 |
| A07 迟刃三绝 | 1.48 / 1.48 · 1.50 / 1.50 · 1.52 / 1.54 |
| A10 五叠断魂 | 1.22 / 0.91 · 1.29 / 1.13 · 1.23 / 1.28 · 1.32 / 1.34 · 1.43 / 1.49 |

（全部 10 套的明细在自检结果 `bossReach.r` 里。）

举剑直劈这类刀，「最先碰到」的高度在头顶附近（1.8–2.0 米），这是对的：劈下来先碰到的就是头。

**跟着体型放大的**（× 1.886）：
- 走路 1.55 → 2.92 米 / 秒；跑 5.2 → 7.84 米 / 秒，跑的动作按 0.8 倍速放，脚下不打滑；
- 各套的开招距离、近身距离；
- 选招的距离档（近 6.8 米、中 12 米）、空闲时走近（12.3 米）、改跑（17 米）、举剑停顿里踏步逼近（4.5 米）；
- 推开玩家的半径 0.85 → 1.6 米；
- 截锋架势的距离 × 1.4；
- 留锋突刺 3–10 → 4.5–13 米、冲刺 11 → 15 米、收在 2.1 米外；
- 跃起的高度（重坠 2.4 → 3.6 米、焚天断界 3.2 → 4.4 米）；
- 踏火震 4 → 5 米、重坠落地 3.4 → 4.3 米；
- 燃刃留痕的高度 1.3 → 1.7 米（巨人的劈砍停在玩家胸口的高度）；
- 剑判定的半粗 0.12 → 0.15、剑尖外多算 0.25 → 0.3（荆棘剑放大后的刃宽）。

**过场与镜头**：
- 出场、转阶段、击败、失败四段过场里围着剑尊的机位按体型放远放高；
- 开战与过场收尾回到玩家身后的镜头由 6.6 米 / 俯仰 0.2 改为 7.8 米 / 0.24；
- 锁定框、头顶高度（`headY`）、终式处决的演出按单位的头顶高度自动跟着变。

### 模型清晰度：笔刷贴图换回原素材的分辨率

- **原因**：笔画模型的颜色来自顶点色，笔触的形状来自五张笔刷贴图（粗毛刷、胶带、墨、油画、纸）。原素材里这五张是 1024 像素（纸是 1024 × 128），第二十四轮导出时（`tools/r24_export_boss30.py`）一律缩到 512 以内。剑尊放大 1.9 倍之后，画面上的笔触被拉糊。
- **换图**：`tools/r26_boss30_tex.py` 不重跑绑定、导出，直接在转换好的 GLB 里把这五张换成原素材的 1024 像素版本，写成 `assets/converted/boss30/boss30_hd.glb`（原 `boss30.glb` 保留）。
  - 原素材是灰度 + 透明：不透明处一律纯白，只有透明度有用。新图的灰度通道全写成白，放大缩小时笔触边缘不会滤进黑边，透明度照原图。
  - 写之前核对过：原图缩到 512 后，透明度与旧图一致；不透明处两边都是纯白。
  - 网格、骨架、动作的压缩流逐字节相同，只整体后移，偏移量随之平移。
  - 文件由 3.8 MB 变为 4.9 MB。
- **其他**：
  - 贴图开了 8 倍各向异性过滤，斜着看的笔触不再糊成一片；
  - 笔画本身是 Tilt Brush 的画风（一笔一笔的刷痕），这是素材的风格，没有去改。

对照图：`docs/screenshots/r26_boss_size.jpg`（同一机位的体型）、`r26_boss_closeup.jpg`（近景的笔触）；录像 `r26_boss_before/after.mp4` 的开头 2 秒。

### 佩剑：assets/sword/sword3（荆棘）

- **用的文件**：第十五轮转出的 `assets/converted/swords/jingji.glb`，本地 +Y 指剑尖、原点在握持处、+X 刃口、+Z 剑面法线。
- **怎么挂**：挂在原装剑的父骨（右手）上。
  - 原点放到原装剑的握点；
  - +Y 对齐原装的剑轴（动作是按它做的）；
  - +X 对齐原装剑身的宽面方向（剑顶点的第二主轴）；
  - 缩放按握点到剑尖的长度对齐，游戏里约 2.11 米。
- **原装的剑**：藏起来，不再显示、不再判定。
- **跟着新剑走的**：
  - 判定、剑光拖尾、剑上的火、燃刃留痕、举剑停顿时剑上聚火、击败时剑脱手落地；
  - 荆棘剑保留它自己的金属、粗糙度、法线贴图，再叠上剑尊的燃火、受击闪白、凝形 / 碎烬着色。

### 节奏：慢刀不再拖

- **举剑停顿缩短约 45%**：例如悬锋重劈 0.45 → 0.26 秒，沉锋双落 0.8 / 0.45 → 0.42 / 0.26 秒，落烬火柱 1.25 → 0.7 秒（各套原值写在配置的注释里）。
- **停顿前后加速**：有停顿的段，举剑那一段按 1.25 倍速放，停顿之后到这一击打完按 1.3 倍速放（蓄满就劈）。
- **招与招之间的空隙**：一阶段 0.75–1.25 → 0.65–1.1 秒，二阶段 0.6–1.05 → 0.5–0.9 秒。
- **快刀不变**。

### 打击感（`CONFIG30.feel`）

刀落到玩家身上，在玩家受击原有的反馈（顿帧 0.045 秒、镜头推一下、玩家闪红、受击声）之上：

| | 命中（快刀 / 重刀） | 被挡（快刀 / 重刀） |

## 四、弹反手感：不再慢一拍

参数 `PLAYER_COMBAT.guard`；规则 `moves.press / enterGuard / defend`；结算 `combat.damagePlayer / lateParry / tickLateParry`。

「慢一拍」的四个来源，逐个改：

1. **按下到举剑差一帧**：原来按下右键先进输入缓冲，下一帧才举剑开窗。现在能举剑就在按下的这一刻开窗。
2. **窗口偏紧**：0.18 → 0.2 秒。
3. **看到碰到才按就来不及**：画面与按键本身就有延迟，看到刀碰到身上的那一刻再按，来招已经结算成受击了。现在加了「迟到的弹反」：
   - **条件**：正面、可弹反、正在出手的近战来招碰到身上的那一刻，玩家没在窗口里、但此刻能举剑；
   - **挂起**：这一下先挂起 0.09 秒，期间无敌，不让别的一下趁机打进来；
   - **结算**：挂起中按下右键开了窗，按弹反结算；到时没按，照原来的受击结算；
   - **不适用**：弹得回的魔弹、不可弹反的、持续伤害不挂起。
4. **连段第二击弹不了**：原来两次开窗至少隔 0.7 秒，弹开第一击、第二击 0.3 秒后就到，按了不开窗，只能格挡。现在：
   - 间隔 0.7 → 0.4 秒，而且只罚「弹空」；
   - 上一次弹反成功，下一次按下立刻再开窗。

另外，重劈（第四式）收招早一点可以举剑 / 闪身（承诺段 0.28–0.74 → 0.28–0.6），弹反不再被自己的终结一刀卡住半秒。

## 五、新放的两个水墨包：用了什么

### 1. `Ink+slash+Collection+1.0.unitypackage`：与第二十轮的同一套素材

不依赖 Unity 解包（`tools/r20_unpack_unitypackage.py`）后，与第二十轮的 `FX_Ink slash.unitypackage` 逐个比对：

- **工具**：`tools/r26_build_ink3.py` 直接从 `.unitypackage` 里按路径读出要用的 8 张，不解包、不写临时文件，拼成 `assets/converted/fx/ink3/ink3.png`（2048 × 1024 灰度，403 KB）与 `ink3.json`。

## 八、已知的取舍

- **最高的几记横扫**：疾锋横斩、迟刃三绝第二、三击的俯身压到上限 30°，剑扫在玩家肩头（约 1.5 米），没有压到胸口——再压就像鞠躬。
- **贴身打剑尊**：玩家贴到剑尊脚边（2 米以内）时，有些横斩会从头顶过去、按头部碰到判定。巨人的剑在远端最低，贴身是一种取舍。
- **剑尊的画风**：笔画模型一笔一笔的刷痕，是 Tilt Brush 原作的风格。本轮把笔刷贴图换回原分辨率、加了各向异性过滤，不重画模型。
- **太极印与地砖**：重劈的地面太极印在演武广场正中那块太极图地砖上，会和地砖的图案重叠；在别处的地面上更醒目。
- **第三组水墨未用的形状**：墨点、飞白、云纹进了贴图集，本轮没用。
