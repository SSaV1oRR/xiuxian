# 第十四轮：剑招动作、剑诀特效与战斗界面

本轮用 `assets/` 里新加的两套素材，做了下面四件事：
- **剑招**：一套完整的攻击招式。修士的剑招、格挡、受击、服丹，以及魔修的出手，都换成 Quaternius 动作库里的真实动作。
- **剑诀特效**：每一招都有对应的特效。
- **战斗界面**：重做，桌面、窄窗口、手机、平板都能用。
- **剑诀面板**：新增，按 K 打开。

两套素材都是 CC0：
- 动作：Quaternius「Universal Animation Library 2 [Standard]」，在 `assets/fighting`。
- 特效贴图：Kenney「Particle Pack 1.1」，在 `assets/special effects`。

改动前的项目备份在 `backups/xiuxian-r13-20261008-1035.zip`。

## 3. 动作重定向（`tools/convert_ual2.py` → `src/actors/anim.js`）

修士与同门的骨架是程序化的：骨盆、胸、头，左右肩肘腕、髋膝踝，共 15 个关节。静止时双臂下垂，每个关节的静止旋转都是单位。动作库是 UE 式骨架，T 字静止，面朝 +Z、左侧在 +X，和修士的朝向、左右一致。

- **转换（离线，Python）**：
  - 每根目标骨取对应源骨，算出源骨相对其静止姿势的世界旋转变化 `D(t) = Q(t)·Q静止⁻¹`。
  - 再乘对齐旋转 `A`，得到目标骨在角色空间的世界旋转 `D(t)·A`。`A` 把目标骨的静止姿势摆成源骨的静止姿势：
    - 手臂：由下垂抬成 T 字，按骨的走向与 +Z 建坐标系对齐。
    - 手：按骨的走向与掌心朝向对齐。
    - 躯干、头、脚：两边静止时都直立、脚掌平放，取单位。
  - 骨盆另存相对静止的位移。
  - 30 帧/秒，四元数 ×32767、位移按毫米量化为 Int16。每帧 63 个数。
- **运行时**：
  - 按时刻取前后两帧插值。
  - 关节的局部旋转 = 父关节（已混合）世界旋转的逆 × 目标世界旋转。
  - 按遮罩权重与程序化姿势做球面插值。遮罩有全身、上身（魔修边走边出手）、双臂三种。
  - 程序化姿势在混合前存下，下一帧开头还原，所以走路、呼吸、发丝衣袖等程序化动作照常从自己的状态继续。
  - 动作停下时按淡出时间平滑交还。
- **剑**：
  - 出剑时右手握剑。握剑方向取自动作库手骨的剑向（`blade`），收剑后剑回鞘中。
  - 剑尖、剑根的世界位置每帧给拖尾用。
- **裙摆**：大幅前踢、后撤时，裙摆的外翻系数夹在范围内，不再翻起。

### 4.2 规则

- **按动作时间轴出剑**：
  - 每帧先由剑诀推进动作时刻、做命中判定，角色再按同一时刻摆姿势。出剑判定与画面同帧。
  - 有顿帧时，整帧时间放慢到 6%。
- **连招**：
  - 出招中按左键会记下来，到可接的时刻接下一式。三式之后有 0.25 秒间歇。
  - 最后一次出剑之后可以用剑诀打断本式。
  - 收势中按方向键可以直接走开。
- **软锁定**：取 7.5 米内（剑气 22、惊鸿 11、万剑 16）得分最低的敌人，得分 = 距离 + 2.4 × 与镜头朝向的夹角。身后远处的不锁。没有目标时朝镜头所对的方向出剑。
- **灵力**：满值 100。交战中每秒回 7，脱战后每秒回 22。
- **剑意**：
  - 出剑命中积攒，每次命中：拂云、回风 5，断水 10，剑气 4，惊鸿 6，破岳每段 6，万剑的飞剑 2。一剑同时打中几个敌人就乘几，最多三倍。
  - 弹反 22。
  - 满 100 时可放万剑归宗。
  - 脱战 8 秒后每秒消散 3。
- **受击**：
  - 魔将的震地会把人掀翻：先播 Hit_Knockback，再播 LayToIdle 起身，期间无敌。
  - 魔将有架势（`poise`），寻常剑招打不乱。只有断水、破岳末式、万剑归宗与弹反能让他失衡。
- **限制**：以下场合剑诀不可用：
  - 御剑、打坐、对话、面板打开时。
  - 室内（丹房、问道殿、通天塔大厅）只能用流云三连和格挡；其余剑诀会提示「屋里施展不开」。
- **收剑**：最后一次出手或格挡 5 秒后收剑入鞘。
- **练剑**：演武广场西侧有三根木人桩，只记伤害，不会还手。

## 5. 剑诀特效（`src/world/vfx.js` + `src/game/skillfx.js`）

### 5.1 底层

- **粒子池**：一张单位面片做实例化。
  - 每个粒子用 7 个 vec4 存位置、出生时刻、速度、寿命、两个方向轴与大小、颜色与不透明度、贴图格号、模式、旋转与自转、重力、阻力、淡入、拉伸。
  - 运动、大小曲线、淡入淡出都在顶点着色器里按时间算。CPU 只在生成时写一次，环形缓冲只上传改动的区段。
  - 四种模式：面向镜头、按速度拉长、给定两轴的平面（刀光、阵纹）、贴地。
  - 加色、透明两池：光用加色，烟与剑阵底纹用透明。
  - 每池一次绘制。流畅画质下粒子数减半。
- **剑光拖尾**：
  - 每帧记下剑尖与剑根（只取剑身外侧六成），画最近 0.16 秒的轨迹。
  - 用 Catmull-Rom 补点，越旧越窄、越淡。
  - 寻常剑招为青白，破岳为金色。
- **残影**：惊鸿与闪身时复制角色当前姿势，生成一个半透明的边缘发光残影，0.34 秒内淡去。
- **屏幕闪光**：大招落地、弹反时整屏闪一下（DOM 层）。
- **配色**：
  - 寻常剑招：剑光 #8fe6ff，芯 #eaffff。
  - 破岳、万剑归宗：金白，#f5c86a 与 #fff1c8。
  - 弹反：金色。魔修：暗红。尘土：灰黄。

- 出手动作提前 `hit − hold` 秒开始播，挥击落下的那一刻正好是伤害结算的那一刻。

### 7.3 验收时发现并改掉的问题

- **调息结束后整格一直发灰**：
  - 原因：调息最后一帧剩下不到半个百分点，四舍五入成 0，与「已结束」的缓存键相同，于是跳过了更新。
  - 改为进位取整。实测五种调息长度都能正确结束并亮一下。
- **连击数压在任务栏上**：挪到左侧。
- **名牌盖住任务栏**：同门名牌、敌人血条、伤害数字原来画在任务栏上面，现在压在屏幕面板之下。
- **剑诀栏压到菜单键**：窄于 1520 的桌面窗口上（含常见的 1366、1280 笔记本）居中的剑诀栏压到菜单键，见 7.2。
- **御剑键与「图」重叠**：手机上新加的「诀」键把菜单行拉长，压到「御剑」键，已左移。
- **界面每帧重写同样的值**：灵力文字、灵力条、气血残影、魔将血条原来每帧都写 DOM，现在只在数值变了时写。
- **传送时没有收住剑招**：传送时正在出的剑招没有收住（拖尾会从原处拉到目的地），已在传送时收招。

## 10. 性能

均衡画质，画布 1600×900，像素比 1。

**不战斗时（与第十三轮同场对照）**：
- **方法**：把第十三轮备份解压到临时目录，用只监听本机的临时服务器提供，与本轮在同一会话里交替测量。
  - 两个页面都先停掉自己的主循环，只按 `tools/perf_r9.js` 的方法手动推进：每轮 3 × 60 帧，末尾 `gl.finish`，取最好的一组。
  - 交替四轮，取中位数。
  - 测完已删掉临时副本，停掉服务器。

| 视点 | 第十三轮 | 第十四轮 | 差 |
|---|---|---|---|
| 山门（gate） | 17.2 ms | 17.8 ms | +0.6 |
| 演武广场 | 17.6 ms | 17.1 ms | −0.5 |
| 绘制调用 | 768 | 770–772 | +2–4 |

差值都在这台机器的测量波动之内（同一视点前后相差 1–3 ms）。
- 本轮新增的每帧开销：两池粒子各一次绘制（无粒子时只是一批退化面片）；动作播放器不播放时直接返回；界面只在数值变化时写 DOM。
- 本次绝对值比第十三轮报告里的数（演武广场 10.8 ms）高：这次两个 WebGL 页面同时开着，机器状态也不同。前后对照以同场交替的结果为准。

**战斗中（本轮版本，演武广场，每帧末尾读回一个像素等 GPU 画完，偏保守）**：

| 场面 | 平均 | p95 | 绘制调用 |
|---|---|---|---|
| 无敌人 | 17.9 ms | 21.1 | 约 535–560 |
| 魔将 + 三名残魂 | 19.1 ms | 20.8 | — |
| 流云三连 | ≤ 20.7 ms | 27.2 | — |
| 破岳 | 21.3 ms | 23.6 | 约 578 |
| 万剑归宗 | 23.2 ms | 30.0 | 约 603–618 |

- 特效的 CPU 开销：主循环（不等 GPU）无特效 17.5 ms，破岳 18.4 ms，万剑 18.8 ms，约 +1 ms。
- 同一帧把特效材质关掉、打开各画 30 次对照，GPU 上的差别在 ±2 ms 波动之内，量不出来。
- 万剑归宗多出的约 60–80 次绘制，主要是 26 把飞剑与巨剑。

## 12. 限制与后续

- **比例差别**：动作库的人形与修士比例不同（修士肩窄、袖宽、腿稍短）。重定向只传旋转（骨盆另传位移）：
  - 个别帧手与剑的相对位置和原动作略有出入。
  - 大步踏进时脚底可能轻微滑动。没有做脚部 IK。
- **宽袖与裙摆**：仍是程序化的发丝衣袖物理，大幅动作时偶尔会穿过手臂。
- **没有音效**：项目里没有音频系统，本轮也没有新的音频素材。打击感靠顿帧、震屏、闪光与特效。
- **魔修行为**：魔修的寻路、出手节奏与数值没有改，只换了动作，并把出手时刻对准伤害结算。
- **触屏攻击键**：触屏上没有单独的大攻击键，流云格就是攻击键。
- **横屏手机**：横屏手机（例如 812×375）界面很挤，没有专门适配。
- **可继续加的动作**：动作库里还有可以接着用的动作，例如跳斩可用 NinjaJump 系列，滑步可用 Slide 系列。加进 `CLIPS` 重跑转换即可。
