# 第十七轮：人物战斗系统（攻击动作、操作、剑诀表现、弹反判定）

本轮重做了玩家的战斗，演武场的对手、通天塔第五十层的镇塔龙君与玩家用同一套规则。沿用现有的金白修士、十把剑器、气血 / 灵力 / 剑意与原有剑诀，另外新增一个控制技能「缚灵锁」。

本轮包括：
- 先查出的实际问题（§1）；
- 动作：在修士骨架上编排了 27 段，另列沿用的动作（§2）；
- 操作：键位、输入缓冲、按住连续攻击、逐招的接招 / 取消窗口（§3）；
- 转向与目标辅助、Tab 锁定（§4）；
- 弹反与格挡（§5）；
- 来招的防御属性（§6）；
- 打击反馈（§7）；
- 剑诀的立体表现与缚灵锁（§8）；
- 演武场与第五十层（§9）；
- 界面与调试（§10）；
- 性能与资源（§11）；
- 自检（§12）；
- 录像与截图（§13）；
- 仍缺少的动作与已知限制（§14）；
- 文件（§15）。

几点约定：
- 改动前的项目备份在 `backups/xiuxian-r16-20261009-0645.zip`；原始素材未改动。
- 下文的数字都取自配置文件（`src/game/combatConfig.js`），或在游戏里按真实的输入、出招、结算代码实测（`tools/r17_suite.js`）。

## 1. 先查出的问题

以下各条都是对照第十六轮的代码（备份里的 `moves.js`、`combatConfig.js`、`pointer.js`、`combat.js`、`duel.js`、`skillfx.js`、`boss50Fight.js`）逐条核实的。

### 动作

1. **普攻**：左键只有三段，用的是动作库（Universal Animation Library）`Sword_Regular_A / B / C` 的截段，外加两段收势。没有第四式，没有蓄力重击，也没有拔剑入势与战斗待机：交战中站着时仍是平常的站姿。
2. **受击**：不分来向、不分轻重，一律播 `Hit_Knockback` 的前 0.24–0.55 秒；破防、麻痹也是这一段。
3. **借用的动作**：
   - 格挡是 `Sword_Block` 的前 0.3 秒定住，挡住与弹反没有各自的动作；
   - 闪身一律是 `Sword_Dash` 的 0.03–0.3 秒（一个向前冲的动作），向后、向左右闪也播它；
   - 剑气借第二式 `Sword_Regular_B`，万剑归宗借 `OverhandThrow`（投掷动作）。
4. **位移两个来源**：动作本身在原地，踏步（`lunge`）由代码按固定时段、固定速度推人，与动作的步子对不上；出招的第一帧就把朝向直接设到目标方向，人瞬间转过去。

### 操作

5. **左键**只在按下的一刻出一剑，按住不会连续出手。
6. **缓冲**：出招中按的任何键都记进同一个缓冲，0.45–0.6 秒内有效，后按的直接覆盖先按的，不分先后轻重。第三式后另有 0.25 秒冷却，期间的点击也记着。
7. **重击**没有独立的键位。
8. **取消**：
   - 闪身几乎在任何时刻都能打断出招，包括出手判定之前与正在出手时（只有万剑归宗、倒地、闪身本身除外）；
   - 剑诀只能在普攻最后一次判定之后打断；
   - 没有逐招的接招窗口、取消窗口与承诺段。
9. **灵力与调息**：剑诀在起手那一刻就扣灵力、进调息，起手被打断照样扣。
10. **失去焦点**只解除格挡，已缓冲的出招照样会出。

### 转向与目标

11. **软锁定**：
    - 每次出招都重新挑目标：7.5 米内（剑气 22 米），镜头前方左右各约 109° 都算，3.2 米内连身后的也算；
    - 不检查墙，隔着墙也会转过去；
    - 没有显式的锁定。

### 弹反与格挡

12. 弹反窗口 0.22 秒，身前 160°。
13. **连点能刷窗口**：再按一次右键就重新开窗，没有间隔，连点右键几乎一直处在弹反窗口里。
14. **按住白得窗口**：按住右键出招时，出剑那一段一过就自动举剑，而每次举剑都重设弹反计时。不必重新按下，就白得一个弹反窗口。
15. **弹反不看来招**：凡是能挡的都能弹（只有第五十层个别招式标了不可弹反）。弹开后，4.5 米内的出手者一律失衡 1.4 秒。
16. **格挡没有消耗**：一律只承受 25% 伤害，按住右键可以一直挡（只有第五十层个别招式带破防）。
17. **魔修的出手没有防御属性**：魔将震地也能举剑挡住，甚至弹反；术士的魔弹弹反后不会弹回。

### 反馈与特效

18. **刀光**是一张月牙贴片，每招的倾角、大小、高度写死，不跟真剑走。
19. **命中火星**出在敌人身体中段的固定位置，不在接触点。
20. **破岳的地面光圈**最大约 11 米宽，伤害半径却是 4.8 米；圆心也不同（光圈在身前 1.5 米，伤害以自身为圆心）。
21. **顿帧**只有第三式、破岳末式与弹反有，同时多次只取最大值，没有间隔规则；普通命中每一下都震屏。
22. **音效**不限叠音：多个目标同时被打中，就同时起好几个声音。

### 演武场、第五十层、资源

23. **演武场的对手**用的也是这三段动作库剑招与固定速度的踏步；被弹反时由玩家这边统一叫它失衡。
24. **第五十层的龙君**被弹反一律只积累架势，不按招式区分收手、打断、作废余下的段。
25. **魔修的资源没有释放**：魔修消散时只从场景里拿掉，自己的合并网格、骨骼贴图、光晕与寒冰罩的材质都没有释放。压力测试里，显存中的几何体与贴图数随刷怪一直增长。

## 2. 动作

### 2.1 新编排的 27 段（`src/actors/cultivatorClips.js`）

**编排方法**（`src/actors/cultivatorPose.js`）：
- **关键姿势**：每一键给握剑点、剑尖方向、刃口（或挥剑的转轴），以及躯干三节的拧转俯仰、左手位置、双脚落点。
- **双臂**：两骨 IK 解出。腕部的握法（前臂扭转 × 肘的位置）在 15° × 20° 的网格上搜索，按以下各项的代价挑最自然的：剑身与前臂的夹角（常态 50–105°）、腕屈（≤ 70°）、前臂扭转（≤ 100°）、够不到的距离；扭转的六成分给前臂。
- **双脚**：按地面参照踩定，随根运动整体前移。换步时脚自动抬起，抬起高度随步幅，最高 0.13 米。
- **剑刃**：用胶囊体检查有没有穿过身体。
- **生成时机**：载入时一次生成 27 段，本机约 102 毫秒，挂进玩家与演武场对手的动作表。

所有站姿以「右脚在前」的中段架势为枢纽：四段普攻都保持右脚在前，收势只需后脚跟一步，不用换脚。

| 动作 | 时长 | 内容 |
|---|---|---|
| `cb_idle` | 2.4 秒循环 | 战斗待机：中段架势，剑尖斜指对手咽喉，左手掐诀护胸，呼吸 |
| `cb_armR_walk` / `cb_armR_run` | 循环 | 拔剑走、跑：只盖右臂（持剑不甩），下身仍是原有的走跑 |
| `draw` | 0.32 秒 | 拔剑入势：由平常站姿右手探到左腰握柄（0.1 秒握住时剑才出鞘），抽剑上提，右脚上步成架势 |
| `atk1` 斜斩 | 0.62 秒 | 剑举到右肩后上方（躯干右拧、重心后移）→ 翻腕前斩、前脚滑出 → 右上至左下 → 送剑、后脚跟半步 |
| `atk2` 反手横斩 | 0.64 秒 | 剑抬到左肩、剑尖指左后（躯干左拧到底、后脚跟上）→ 自左向右横斩、前脚再进 |
| `atk3` 突刺 | 0.72 秒 | 收剑于右腰、坐胯 → 弓步拧腕平刺（根运动 0.36 米）、左手后摆 → 后脚跟上 |
| `atk4` 重劈 | 1.12 秒 | 后脚上步双手合握 → 举过头顶、剑尖指后（明显蓄力）→ 震脚劈下、身体前俯 → 起身、松开左手、后脚跟上（收势长） |
| `hv_charge` | 循环 0.28–1.2 秒 | 蓄力：压低身形，剑拖到右后 |
| `hv_release` | 0.95 秒 | 蓄力横扫：左脚上步，横扫二百余度，退步收势 |
| `guard` | 1.7 秒循环 | 格挡：横剑斜架于身前，左掌托住剑身 |
| `block` | 0.28 秒 | 顶架：挡住时双臂一沉、重心后坐 |
| `parry` | 0.42 秒 | 弹反：剑由左上翻到右上磕开来招，回到中段（反击的架势） |
| `guard_break` | 0.95 秒 | 破防：剑被震向右后上方、左臂甩开、后仰，踉跄后退 0.45 米，稳住 |
| `hit_f` / `hit_b` / `hit_l` / `hit_r` | 0.38 秒 | 四向轻受击：躯干按来向后仰、前俯或侧折 19–24°，退半步 0.14 米 |
| `hit_heavy` | 0.8 秒 | 重击退：剑被磕高、后仰，后退 0.85 米，稳住 |

| `dodge_f` / `dodge_b` / `dodge_l` / `dodge_r` | 0.45 秒 | 四向闪身：蹲 → 双脚离地（腾空的一段才给位移）→ 落地缓冲 |
| `cast_qi` | 0.56 秒 | 剑气：剑指自剑根抹到剑身中段 → 横斩（0.2 秒放出） |
| `cast_seal` | 0.85 秒 | 缚灵锁：竖剑当面、左手掐诀 → 推掌，剑顺势指向对手（0.32 秒放出） |
| `cast_ult` | 1.9 秒 | 万剑归宗：举剑指天（0.4 秒）→ 定住 → 剑指敌阵（1.28 秒） |

**编排时的自动检查**（每段的最大值）：
- 剑身与前臂的夹角超出常态（50–105°）的量：27 段中 23 段不到 30°；超过的是斜斩 36°、万剑归宗 45°、重劈 68°、破防 69°（破防是没有握剑的左手被甩开）。
- 四肢够不到设定点的最大偏差：普攻 3–7 厘米（多在换步的脚上）；万剑归宗举剑指天差约 0.3 米。
- 剑刃离身体的最近距离：普攻 2.8–12 厘米，没有穿过身体。
- 超出常态的几处，见 §14。

### 2.3 混合与位移

- **交叉淡化**（`src/actors/cultivator.js`）：
  - 接招时 0.07 秒，首尾姿势本就相接；
  - 由平常站姿直接出招时 0.16 秒，换步不显得一下跳过去；
  - 其余 0.1 秒。
- **淡化中两段先互相混合，再盖到底层**：之前是两段各自盖底层，淡化中会漏出底层的走跑姿势。
- **位移只有一个来源**：动作的根运动按朝向换成速度，交给原有的移动与碰撞（`player.update`），不穿墙。
  - 有辅助目标时，停在它身前 0.75 米，不往里挤。
  - 招式自己不给位移的帧里，人站住，不留走跑剩下的速度。
- **闪身的位移只在双脚离地的一段给**（0.06–0.24 秒），速度按半个正弦起落，落地前后不动。

## 3. 操作

### 3.1 最终键位

设置面板的「操作说明」里显示的是同一份。

| 键 | 作用 |
|---|---|
| W A S D / Shift / 空格 | 行走 / 疾行 / 跳跃（不变） |
| 移动鼠标 | 转动视角（点击画面锁定鼠标，Esc 释放；不变） |
| 鼠标左键 | 点一下出一剑；按住连续出手：斜斩 → 反手横斩 → 突刺 → 重劈，第四式收势后再从第一式起；松开即停（当前这一下打完） |
| 鼠标右键 | 按下、真正举剑的一刻开弹反窗口；按住为格挡；松开放下 |
| **Z / 鼠标中键**（新） | 按住蓄力（三档），松开出手；满蓄斩出一道短程剑气 |
| **1**（新） | 缚灵锁（对话、传送菜单中仍是选项 1） |
| **Tab**（新） | 锁定 / 解除锁定身前的对手 |
| Q / R / T / V | 剑气·新月 / 惊鸿掠影 / 破岳 / 万剑归宗（不变） |
| C | 闪身（御剑时为下降；不变） |
| G | 服丹（不变） |
| E、F、K、P、M、J、B、Esc | 交互、御剑、剑诀、佩剑、舆图、行记、行囊、设置（不变） |

**键位冲突检查**：
- Z、中键、Tab 原来都没有用；Tab 已在全局阻止浏览器的焦点切换。
- 数字 1–4 只在对话、传送菜单打开时选选项：这时剑诀键整体不响应，没有冲突。
- 中键在鼠标锁定时阻止了浏览器的自动滚动。

### 3.2 输入的处理（`src/game/moves.js`）

- **按下即记、下一帧处理**：键鼠事件只记下「游戏时刻」，出招在下一次更新里做；顿帧中按下的照样记下，顿帧过后按合法窗口执行。
- **只有一个缓冲**，有效 0.15 秒。新按的键按优先级替换旧的：闪身 5 > 格挡 4 > 剑诀 3 > 重击 2 > 普攻 1。已缓冲的更要紧时保留它；过期丢弃。
- **按住左键 = 持续攻击**：
  - 到了该招的接招窗口就自动出下一式，第四式要等收完（1.05 秒）才从第一式再起；
  - 松开左键只是不再续，当前这一下照常打完；
  - 按住右键时不出普攻；松开右键而左键仍按着，到允许的时刻恢复连续攻击。
- **清空**：打开界面、失去焦点、切换窗口、过场、换场景、力竭、结算时，清掉一切按住的键与缓冲。
  - 蓄力中失焦或打开界面，这次蓄力作废，不当作松开 Z 打出去；
  - 打开界面时当前招式立即收住。
- **鼠标**：只在锁定鼠标时处理按键。点击画面锁定的那一下不出剑；打开任何界面都会释放鼠标。
- **取消时的资源**：
  - 剑诀在「放出」的那一刻才扣灵力、进调息。放出前被取消，什么都不扣，只留 0.4 秒再按间隔（防止反复起手取消）。
  - 剑诀起手到放出之间，灵力条上先画出要扣的一段（淡色），取消即消失，与实际扣除一致。
  - 已放出的弹体（剑气）按自己的规则继续飞；已造成的伤害、已扣的灵力与调息不回退。
- **命中只结算一次**：每一段判定对同一目标只结算一次；接招、取消、重新按键都不会刷新命中记录（`hitSets` 按招式实例与段号记）。

### 3.3 各招的窗口（`PLAYER_MOVES`）

- **接招**：这段时间里有左键（按住或缓冲）就接下一式。
- **格挡 / 闪身 / 剑诀**：可以被这三种输入取消的时段。
- **承诺段**：什么都取消不了。
- **走开**：过了这一刻按方向键，即收招走开。

## 4. 转向与目标

- **转向**：每招配 `[前摇, 有效段, 收势]` 三档每秒最大转角（弧度）。例如：
  - 普攻 16 / 2.5 / 6，突刺有效段 1.8，重劈 12 / 1.2 / 4；
  - 前摇里追着目标（或镜头方向）转，出手时只能慢慢转，挥剑中不会突然转过半圈。
- **近战辅助**（`pickAssist`）：
  - 范围：普攻 4.0 米（突刺 4.6），镜头方向左右各 55° 以内（1.6 米内不限角度），高低差 2.5 米内；
  - 不隔墙：胸口到胸口打一条射线；
  - 候选：只有魔修、木人桩、切磋对手、守关龙君，不含同门与护宗双龙；
  - 优先角度小的，其次近的；
  - 选定后 0.6 秒内不换；3 秒内，新目标的得分要比原目标好 0.7 以上才换；
  - 没有目标就照镜头方向出招。
- **锁定（Tab）**：
  - 锁定身前 20 米内、镜头方向左右约 52° 以内看得见的对手（不锁木人桩）；头顶的星芒转金，脚下的环转金加速；
  - 出招、举剑都对着它，镜头仍由玩家转；
  - 解除：再按 Tab；对手倒下；超出 24 米；被挡住超过 1.5 秒。
- **剑气、缚灵锁**的取向同样按辅助 / 锁定目标，没有目标照镜头方向。

## 5. 弹反与格挡

### 5.1 参数（`PLAYER_COMBAT.guard`）

| 参数 | 值 |
|---|---|
| 弹反窗口 | 0.18 秒（按下右键、真正进入格挡的那一刻开） |
| 弹反再开间隔 | 0.7 秒（与上次开窗不足 0.7 秒的按下只举剑、不开窗） |
| 正面扇区 | 120°（以人物实际朝向为准，不看镜头） |
| 守势 | 100；格挡一次按来招扣（见 §6），难挡的 ×2.5；停手 1 秒后每秒回 30（举着剑时只回 2.5） |
| 破防 | 守势扣光：踉跄 0.95 秒（`guard_break` 动作），1.25 秒内举不起剑，之后守势先回到 35 |
| 弹反收获 | 回 20 守势、12 灵力、22 剑意；随后 0.9 秒为反击窗口：出手伤害 ×1.35、架势 ×1.6，命中时显示「反击」 |
| 举剑移动 | 速度 ×0.45 |
| 连续受击保护 | 3.5 秒内第 3 次受击反应后，给 1 秒护体 |

### 5.2 判定顺序（`moves.defend`，由各出手者的命中判定调用）

1. 闪身无敌中：「闪」，不受伤。
2. 同一来招的同一段已经结算过：不再结算（按「来招 id # 段号」记）。
3. 弹反，下面六条全部成立才算：
   1. 处于有效弹反窗口：举着剑，且窗口由一次新的按下、真正进入格挡时打开，未过 0.18 秒。按住不放、连点都不会延长或重开。
   2. 来招正处于有效命中阶段（`spec.active`）：近战在出手者自己的命中时刻结算，弹体在飞行中碰到时结算。
   3. 来招实际碰到了人：只有出手者自己的命中判定（扇形、圆、胶囊、弹体碰撞）判中了才会走到这里。
   4. 来向在正面 120° 内：用接触点相对人物朝向判断。龙君横扫用扫向一侧的接触点，不是爪尖。
   5. 来招配置为可弹反（`spec.parry`）。
   6. 这一段尚未结算（第 2 步）。
4. 格挡：举着剑、来向在正面、来招可格挡。扣守势、漏过一部分伤害；守势扣光即破防（漏伤至少 35%）。
5. 其余一律受击：按来向挑轻受击动作，重击按配置击退或击倒；霸体招式中伤害打折、不演轻受击。

**几种情况的结果**：
- 侧后方来招、不可弹反的来招、窗口已过：正常走格挡或受击，不显示弹反特效。
- 正在出剑时按右键：要到该招允许格挡取消的时刻才真正举剑，那时才开窗口。出剑中不会提前获得弹反或减伤。
- 一直按着右键接住出剑收势（按住左右键交替）：自动举剑，但不开弹反窗口，要弹反须重新按下。

### 5.3 帧率

弹反窗口、缓冲、守势、连招时刻全部按游戏时间（dt）计算。实测弹反窗口：

| 帧率 | 窗口实际长度 |
|---|---|
| 30 | 0.200 秒 |
| 60 | 0.183 秒 |
| 144 | 0.181 秒 |

窗口的起止只能落在帧上，30 帧时向上取到 0.2 秒；见 §12.2。

## 6. 来招的防御属性（`ATTACK_DEF`）

**属性的含义**：
- `block`：true 可格挡；`hard` 难挡（扣守势 ×2.5、漏伤多，并有出手提示）；false 不可格挡。
- `parry`：可否弹反。
- `deflect`：弹反时把弹体反弹回出手者。
- `guardCost`：格挡一次扣多少守势；`chip`：格挡时漏过的伤害比例。
- `onParry`：被弹反时出手者的反应。
- `parryEnds`：多段来招里，弹反其中一段后余下的段是否作废。
- `posture`：弹反守关龙君时给它积累的架势。
- `tell`：出手提示。

| 类别 | 格挡 | 弹反 | 守势 / 漏伤 | 弹反后 | 多段 | 提示 |
|---|---|---|---|---|---|---|
| `claw` 爪击 | 可 | 可 | 18 / 12% | 收手一顿（recoil） | 余下的段照常 | 无 |
| `blade` 刀剑 | 可 | 可 | 16 / 10% | 失衡 | 余下的段作废 | 无 |

| `aoe` / `thunder` / `fire` / `grab` | 不可 | 不可 | — | — | — | 头顶红色「危」字、地上深红圈 |
| `breath` 吐息 | 可 | 不可 | 7 / 35% | — | 逐跳结算 | 无 |
| `bolt` 魔弹 | 可 | 可，**弹回** | 12 / 15% | 无 | — | 无 |

每一次出手在开始时就带上这些属性，招中途不变。不可格挡的一律是同一种提示：「危」字 + 深红圈。

## 9. 演武场与第五十层

两处与宗门、秘境用同一套玩家规则：输入、出招、剑诀、格挡、弹反、守势、反击、受击。

**演武场的对手**（`src/game/duel.js`）：
- **动作**：普攻改用玩家同一套编排动作（atk1–atk4），受击按来向，被弹开用 `guard_break` 的前段，被缚用 `stagger`。
- **位移**：踏步改成动作的根运动。
- **被弹反**：
  - 不论是否霸体，这一轮进攻作废；
  - 寻常剑招失衡 1.15 秒，重劈 1.5 秒（困难 ×0.85）。
- **来招属性**：见 §6。
- **对手自己的格挡**：照旧（正面、举剑时只受一成半到两成半）。

**第五十层的龙君**（`src/game/boss50Fight.js`、`boss50Moves.js`）：
- **弹反结果逐招配置**（§6），并按招式配置决定是否作废余下的段。
- **架势**：
  - 弹反只积累架势，攒满 100 才长时间跪地失衡；
  - 不作废后续的招式（双爪追猎）被弹反时只轻晃 0.4，免得把第二爪的路线带偏；
  - 可打断的招式被弹反即打断（短暂受击）；
  - 玩家出手的架势按招式给（`posture`）。
- **缚灵锁**：如上。龙珠可弹回龙首。
- **二阶段**：保留第十六轮更快的出手、移动与更短的僵直；被弹反时架势 ×0.85。
- **出场、转阶段、胜利、失败处决**：清掉玩家的按住与缓冲（`releaseInputs` → `clearInput`）。
- **重试**：重置龙君（动作、AI、架势、危险物、特效）与玩家（招式、举剑、缓冲、守势、反击窗口、锁定、无敌、顿帧、特效池）。

**本轮修的两处场景切换问题**：
- **演武场**：切磋进行中换了场景（例如测试里直接入塔），比试圈仍每帧把人拉回宗门演武场的坐标。现在场景一换即收掉这场切磋（对手、界面、监听）。
- **第五十层**：守关战进行中不经「离开」而直接换了场景，龙君仍在更新，把人拦回封印阵，并且一直占着守关战的状态，宗门里的木人桩、魔修因此打不中。现在一旦不在第五十层即拆除这一场。
- 正常游玩里这两处只能经由各自的「退出」离开，但两处都已加上保护（`arena.js`、`boss50Fight.js` 的 `update` 开头）。

**本轮自己引入、已修好的一处**：「同一段来招只结算一次」按「招式编号 + 段名」去重。龙君的落雷、火柱、冲击环这类危险物没有段名，紫焰吐息的每一跳又共用一个段名，于是同一招里第一下之后都被当成重复、不再结算：吐息只剩一跳，天罚落雷三道只中一道。
- 现在没有段名的危险物每一次各算一段，吐息每一跳各算一段（`boss50Fight.specFor`、`boss50Moves` 的吐息）。
- 修后实测：站着不动，天罚落雷三道各中 22（修前只中第一道）；举剑时紫焰吐息六跳都挡下，各漏 2.4（修前只结算第一跳）。双爪、三段、龙珠的结算与修前相同。

## 14. 仍缺少的动作与已知限制

1. **击倒与起身**：仍是动作库的 `Hit_Knockback` + `LayToIdle`（第十五轮重定向），没有为这个人物重新编排，倒地只有向后一种。
2. **沿用动作库的剑诀**：惊鸿掠影（`Sword_Dash`）、破岳（`Sword_Heavy_Combo`）、服丹（`Consume`）仍是动作库的动作，起手、释放、收势是原动作自带的，没有按新的握剑重新编排。
3. **没有收剑入鞘的动作**：脱战 5 秒后剑直接回到鞘中。
4. **没有手指骨**：剑指抹剑、掐诀只能靠手的位置与朝向表现，手指不会并拢、屈伸。
5. **没有空中攻击**：跳跃、御剑中不能出剑。
6. **几处极限姿势**（编排检查里超出常态的地方）：
   - 重劈：举剑过顶到劈落（0.1–0.5 秒），左手合握时腕部扭转大（最大 168°），已截住，不会折断外观；
   - 万剑归宗：举剑指天时，右手够不到设定的高度（差约 0.3 米）；剑指敌阵的一刻腕屈较大；
   - 破防：被震开的左臂扭转大（有意的甩臂）；
   - 拔剑：0–0.1 秒剑在鞘中，这时的「穿模」不可见。
7. **滑步**：蓄力横扫以前脚为轴转身时，前脚掌约有 0.3 米的转动挪移；反手横斩约 0.2 米（§12.6）。肉眼不明显，但不是零。
8. **未改的出手动作**：魔修的出手动作（`Zombie_Scratch`、`OverhandThrow`、`Sword_Regular_B`、`Melee_Hook`）与演武场对手的震地（`Sword_Heavy_Combo`）。
9. **没有物理**：受击、击退都是关键帧动作，没有布娃娃。
10. **数值**：只由脚本与规则机器人试过，手感（窗口、守势、顿帧）还需要真人试玩再调；参数都集中在 `combatConfig.js`。
11. **触屏**：剑诀栏的格子可以直接点按：按住「重」格蓄力，按住「御」格格挡。「流」格是点一下出一剑，触屏上没有做按住连续出手。
