# 第十五轮：金白修士、剑器与演武场

本轮在现有的引擎、角色控制、战斗、宗门与存档系统上做了三件事：
- **换人物**：玩家外观换成 `assets/figure/gold_cultivator_v1_model_only/gold_cultivator.glb` 的金白修士。移动、打坐、出剑、格挡、交互、御剑都保留。
- **剑器**：`assets/sword/` 里的剑整理成 10 把可换的佩剑。每把剑有自己的握持参数，按 P（或行囊、演武选择界面）更换，换下立即生效并存档。
- **演武场**：在天阶东侧新开一方台地，台口有演武教习韩铮。可与三位对手按三档难度、两种方式切磋，有完整的流程、结算与记录。

几点约定：
- 原始素材一律只读不改。转换结果都写在 `assets/converted/figure/`、`assets/converted/swords/`，转换脚本在 `tools/`。
- 改动前的项目备份在 `backups/xiuxian-r14-20261008-1255.zip`。

## 3. 人物替换

### 3.1 转换（`tools/convert_cultivator.py` → `convert_cultivator.mjs`）

**网格**：网格、蒙皮、骨骼原样保留。

**贴图**：
- 缩到 2048，存 JPEG。法线、金属度-粗糙度用 4:4:4，不做色度抽样，免得金饰边缘发花。
- 另出减面 1/3、贴图 1024 的 `cultivator_lo.glb`，给流畅画质与演武场的对手用。

**自带动作**：保留。
- 两段带根运动的（疾跑、前冲）减去骨盆匀速前移，改成原地。
- 除骨盆以外各骨的位移轨道（就是骨长）删掉。

**重定向**：把 UAL2 动作库重定向到这副 A 字骨架，共 20 段：
- 剑招 Regular A/B/C（含收势）、Regular_Combo、Heavy_Combo、Dash
- 格挡 Sword_Block
- 受击 Hit_Knockback、起身 LayToIdle、失衡 Idle_Shield_Break
- 服丹 Consume、掷剑 OverhandThrow
- 跳跃 NinjaJump ×3、采摘 Farm_Harvest
- 抱臂 Idle_FoldArms_Loop、点头 Yes

做法：
- 源骨的世界旋转变化，乘上把两边静止姿势对齐的旋转，再换成相对父骨的本地旋转。
- 骨盆位移按髋高比（1.139）缩放。

**着地**：
- 每帧检查：脚踝低于静止高度时抬起骨盆，三帧平滑。
- 脚尖低于静止高度时转脚把它抬起来。
- 实测：待机 0 厘米，走路 ±2 厘米。

**自制姿势**：
- `Idle`：取 UAL2 收势末帧的站姿，叠一点呼吸起伏，头颈略抬。
- `Fly`：御剑站姿。

**步速**：从动作本身量出每个步伐周期走过的距离，写进 `cultivator.json`。走 1.533 m/s、跑 4.902 m/s。

### 3.2 运行时（`src/actors/cultivator.js`）

**底层**：待机 / 走 / 跑按速度混合。
- 走与跑共用一个步伐相位，相位推进 = 速度 ÷ 周期距离，所以脚底基本不滑。
- 对手往后退时倒着放。
- 腾空、打坐、御剑、采药各自淡入淡出。

**出招层**：`moves.js` 照第十四轮的方式调用 `anim.play / stop`。
- 剑招用全身遮罩。
- 格挡用上身遮罩，下半身照常走。

**外观**：
- **比例**：人高 1.72 米，与门洞、台阶、同门弟子的比例对得上。
- **材质**：不发光；金饰靠金属度-粗糙度贴图显出金属感，白衣是粗糙的布面。
- **夜里**：靠月光与灯光照亮，见 `r15_shot_night.jpg`。
- **阴影**：投影、受影都开，单面不透明，没有排序问题。

**保留的操作**：

| 操作 | 实现 |
|---|---|
| 视角、出剑、格挡 | 移动鼠标转视角、左键出剑、右键格挡，`pointer.js` 不变 |
| 镜头 | 跟随镜头、遮挡缩距、碰撞体（半径 0.35 米）不变 |
| 打坐 | 自带 `Sit_Cross_Legged_on_Floor` |
| 采药 | UAL2 `Farm_Harvest` |
| 跳跃 | UAL2 `NinjaJump_Idle_Loop` |
| 御剑 | 自制 `Fly` 站姿 |

## 4. 剑器装备

**挂点**：
- 握剑挂点在右手手骨 `RightHand` 上。
- 握持方向取自动作库：剑从拇指一侧伸出，剑面法线朝掌心，原点在掌心。
- 每把剑再按自己的 `grip` 微调：沿手指 `along`、朝掌心 `inward`、沿剑身 `dy`、绕剑身 `roll`、缩放 `scale`。
- 实测十把剑都是剑柄在掌中、护手在虎口之上、剑尖朝前，没有掉落或反握。见 `r15_shot_grips.jpg`。

**收剑**：
- 剑插在左腰的鞘里，剑柄露在鞘口外，按各剑的 `hip` 挂接。
- 蟠龙用原装刀鞘，其余用生成的鞘。见 `r15_shot_katanas.jpg`。
- 出招、格挡与收势后 5 秒内剑在手，之后入鞘。

**更换**：
- 入口：P、行囊里的佩剑卡、演武界面的「更换佩剑」。
- 面板有名称、缩略图、旋转预览、长度与说明。见 `r15_shot_swordpanel.jpg`。
- 佩上即换：手中、鞘中、御剑的飞剑一起换，旧实例先拆掉。
- 当前剑的 id 记在存档里，刷新后恢复。
- 第一版各剑数值相同，只换外观与握持。

**攻击**：
- 沿用第十四轮的命中与伤害：到了动作的出剑时刻做一次扇形 / 圆形判定，伤害只在有效帧内。
- 同一招的同一个判定点只结算一次。
- 刀光拖尾取剑尖与护手上沿的世界坐标，跟着剑刃走。

**御剑**：
- 飞剑就是当前佩剑，按 2.1 米缩放。
- 御剑时手中的剑隐去；飞剑出鞘时鞘中的剑也隐去，落地后剑回鞘。任何时刻只看得到一把剑。见 `r15_shot_flight.jpg`。

**显存**：
- 剑按引用计数（玩家、对手）。换下且没人用的剑释放贴图与几何体的显存，模板留在内存，再佩时重新上传。
- 实测把十把剑挨个佩一遍再换回赤霄，渲染器的贴图数回到原值（173 → 175 → 173）。

### 6.2 难度（改的是行为，不只是气血）

| | 简单 | 普通 | 困难 |
|---|---|---|---|
| 反应延迟（看到你起手后多久才反应） | 0.55 s | 0.34 s | 0.20 s |
| 前摇定格（连招里后几招减半） | 0.42 s | 0.26 s | 0.18 s |
| 两轮进攻之间的调息 | 1.7–2.6 s | 1.0–1.7 s | 0.6–1.1 s |
| 一轮最多几招 | 1 | 2 | 3 |
| 收势破绽 | 0.80 s | 0.45 s | 0.24 s |
| 格挡 / 反刺 / 闪避准头系数 | 0.45 | 0.80 | 1.12 |
| 出招前追着转身的快慢 | 4 | 7 | 11 |
| 追击积极程度 | 0.35 | 0.70 | 1.00 |
| 失衡后的霸体 | 0.9 s | 1.0 s | 1.4 s |
| 移动快慢 | ×0.85 | ×1 | ×1.12 |
| 气血 / 伤害 | ×0.8 / ×0.7 | ×1 / ×1 | ×1.25 / ×1.22 |

### 6.3 不作弊的规矩

- **不读尚未执行的输入**：对手每帧只记下「看得见」的玩家状态，按反应延迟之后的那一份行事。看得见的状态包括：
  - 正在出的招到了哪一段（起手 / 收势）；
  - 是否举剑、是否倒地；
  - 位置。

  他看不到玩家按了什么键。每一招只判一次要不要举剑或闪开。
- **没有零前摇**：每一招都先放到「定格」那一刻停住，地上同时亮出红色预警（扇形 / 圆形），填满即出剑。从预警出现到出剑的最短时间：
  - 困难的连招后几招：约 0.32 秒；
  - 困难的第一招：0.42 秒；
  - 突刺 0.52 秒，震地 0.79 秒。
- **没有无冷却**：每轮进攻之后必有调息；突刺另有冷却（简单 / 普通 / 困难：7 / 5 / 3.5 秒），震地冷却 8–11 秒。
- **出剑判定**：在动作的出剑时刻做一次，一次挥剑只结算一次。出剑那一下方向锁定，可以侧闪躲开。
- **倒地、起身时不受伤害**（点到为止）。失衡结束、起身之后有一小段霸体：寻常剑招只让他一顿，打不断他的出招；重击（断水、破岳末式）与弹反照样打断。不然一味连砍就能把对手一直压在失衡里。

### 6.4 方式

- **自由练习**：
  - 对手不主动出手，可以放心试招、练连击；
  - 按 H 复原双方气血、灵力；
  - 按 U 让他隔 2.3–3.6 秒出一剑，前摇多 0.35 秒，用来练格挡与弹反；
  - 对手被打倒片刻后复原，不判胜负；
  - 玩家气血见底也只是原地复原。
- **正式切磋**：正常攻守，一方气血耗尽分胜负。

## 7. 流程（`src/game/arena.js`）

```
与教习交互 → 演武选择 → 整备（载入资源）→ 入场就位 → 倒计时 → 交手 → 结算 → 再战 / 换对手 / 返回
```

**演武选择界面**：
- 内容：三张对手卡（换色圆标、身份、佩剑、打法、标签、该难度的战绩）、难度、方式、当前佩剑（可更换，换完「返回演武」回到这里）、规矩、开始 / 取消。
- 上次的选择记在存档里。见 `r15_shot_menu.jpg`。

**整备**：
- 点「开始」后载入对手用的减面人物模板（只载一次）与对手的佩剑。
- 载入期间按钮显示「整备中……」，不能开打。
- 15 秒载不下来、或载入出错，就在界面里写明原因，按钮变「重试」，也可以取消返回。

**入场**：
- 黑场里玩家复原气血、灵力、冷却、剑意、连击，站到圈南；对手站到圈北。
- 倒计时「三、二、一、开始」，期间双方都不能出手、不能走动、不能跳，所以不会有伤害。

**交手中**：
- 顶部显示对手身份、难度、方式、计时，以及「X 退出切磋」（自由练习另有 H、U）；对手血条在下方。见 `r15_shot_duel.jpg`。
- 不能御剑、交互、换剑，会提示按 X 退出。
- 打开任何界面（设置、舆图……）时切磋暂停：对手不动、计时不走。
- 魔影袭山时切磋中止，送回台口。

**胜负**：
- 对手气血归零：判胜，对手倒地，AI 立刻停下。
- 玩家气血归零：判负，倒地。不走宗门的「力竭醒来」，没有任何惩罚，退场时气血复原。

**结算**：见第 8 节，`r15_shot_result.jpg`。
- 再战：在黑场里拆掉上一场，按同样的选择重新布置，位置、气血、冷却、临时状态、计时、统计全部复原。
- 换对手：退场后打开演武界面。
- 返回 / Esc：退场。

**退出**：X 键或「返回」，回到台口教习身前、面朝教习。

**拆除**：
- 对手（模型、换色材质、骨骼矩阵贴图、护体剑罡、生成的剑鞘、头顶血条、预警圈）；
- 伤害事件监听、标题与倒计时的界面；
- 对手佩剑的引用（没人用就释放显存）；
- 离场时对手模板的显存。

**按键与鼠标**：
- 打开界面时释放鼠标锁定（沿用原有逻辑）。界面上的点击只在未锁定时发生，不会出剑。
- 点「开始 / 取消 / 再战 / 返回」关掉界面时，就用这一下点击重新锁定鼠标，恢复操作。
- 开打、分出胜负、结算、退出时，清掉键盘、触屏摇杆的按住状态，放下格挡。不会自己走、自己出剑或一直举着剑。

## 8. 结算与记录

**统计**全部来自战斗系统的伤害结算事件（`combat.emitHit`，按实际掉的气血记）：
- 用时；
- 造成伤害（命中次数、被对手挡下的次数）；
- 承受伤害；
- 有效防御：举剑挡下；
- 精准格挡：刚举剑的 0.22 秒内挡住，即弹反；
- 闪身避开；
- 最高连击。

**记录**：
- 正式切磋取胜才记：每位对手、每档难度各记胜场、首胜时间、最佳用时，存档。
- 结算里写明是否首胜、是否刷新最佳用时。
- 选择界面的对手卡上显示所选难度的战绩。

**没有可刷取的奖励**：不发修为、灵石或物品，界面上也写明了。

## 10. 性能

**换人物前后**：
- 把第十四轮备份（本轮改动前）的代码起在另一个端口，与本轮在同一会话里交替测三轮，取中位数。
- 条件：1600×900、像素比 1、巳时、含 `gl.finish`；两个页面都停掉自己的动画循环。

| 视点 | 改动前 | 本轮 |
|---|---|---|
| 山门 | 13.76 ms | 13.97 ms |
| 演武广场 | 11.93 ms | 12.08 ms |
| 云顶 | 10.44 ms | 10.02 ms |
| 广场近景（镜头 3.2 米，人物占满画面） | 12.40 ms | 11.48 ms |

差值都在这台机器 1–3 ms 的测量波动之内。

本轮每帧多画约 40 万个三角形，主要是 18.5 万面的人物，阴影里再画一遍。绘制调用反而少了约 20 次：原来的程序化人物由几十个部件组成，现在是一个蒙皮网格加剑与鞘。

**演武场切磋**（同样条件）：

| | 帧耗时 | 绘制调用 | 三角形 |
|---|---|---|---|
| 不切磋 | 9.2–10.6 ms | 372 | 437 万 |
| 切磋中 | 10.8 ms | 379 | 453 万 |

对手用减面版（约 6.3 万面）。差值同样在波动之内，退出后绘制调用与三角形回到原值。

**载入**：
- 均衡 / 精美画质开局多载 `cultivator.glb` 10.3 MB 与当前佩剑约 1 MB；流畅画质载 4.1 MB 的减面版。
- 其余剑在佩上、预览或演武场需要时才载。
- 对手模板 4.1 MB 在第一次进演武场时载入。

## 13. 限制与后续

**人物**：
- **手指**：模型没有手指骨，握剑时手不会合拢成拳，剑从半张的手中穿出；握持点、方向都对。
- **脚尖**：少数重击帧里脚尖仍会低于地面约 10 厘米。
- **衣摆**：大开大合的剑招里长袍下摆会被腿撑开、偶有穿插。没有布料模拟；运行时夹大腿会让脚陷地，已去掉。
- **对手只用减面版**：近看比玩家略糙；面部、金饰在对照图里差别不大。

**平衡**：
- 平衡按机器人对打调到「简单人人能赢、困难乱砍必输、细心可胜」。真人手感（尤其困难的护法教习）可能还要再调。
- 数值都在 `duel.js` 的 `OPPONENTS` 与 `DIFFS` 两张表里。

**剑器**：
- 第一版所有剑数值相同。
- 蟠龙以外的鞘是生成的，素材里没有。
- 各剑的握持参数是逐把看过调的，腰间挂接是同类剑共用的默认值。

**演武场**：
- 没去过时舆图上是「？？」，去过才标名字；没有专门的任务指引。
- 只能一对一。观战的同门、多人车轮战都没有做。
