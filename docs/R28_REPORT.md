## 一、改前：撞上的那一下

第二十七轮的演出里，凤凰 10.5 秒、雷龙 10.7 秒撞入敌人。撞上的一刻只有：
- **画面**：撞入处一团墨（序列帧）、十来个墨点、几团淡墨雾；龙另有几点白光；
- **地上**：什么都没有，八卦 10.55 秒起在同一处展开；
- **镜头**：不动；
- **声音**：各一声 `inkHit`（0.75、0.85）；10.6 秒一声锣与低鸣。

只有空中的一小团墨，地面、镜头、声音都没有「砸下来」的反馈（`r28_crash_compare.jpg` 上一行）。

## 三、过程中发现并修掉的问题

### 1. 墨迹盖住了八卦

第一版：
- 落点的裂纹墨迹留 2.2 秒，墨柱落地的墨滩留 1.4 秒；
- 余震落在落点四周 1.2–3.8 米。

这些都在八卦（普通敌人半径 2.1 米）上。录像逐帧对照，11.35–12.2 秒八卦几乎看不出来（`r28_bagua_fix_compare.jpg` 中间一行）。

改为：
- 落点的裂纹墨迹只留 0.8 秒（`cracks.decal`），墨柱落地的墨滩只留 0.7 秒（`splat`）；
- 放射的墨裂由八卦外沿（0.92 × 八卦半径）往外裂；
- 余震落在八卦外沿之外 0.3–2 米。

撞上那一下（10.7–11.0 秒）仍是满屏的墨；11.35 秒起八卦与第二十七轮一样看得清（同图下一行）。

### 2. 镜头的一顿与震屏没有上画面

第一版把偏移加在演出每帧摆的镜头上，但演出期间 `game.freeCam` 指着演出机位 `camObj`。主循环在演出之后又按 `freeCam` 摆了一次镜头，把偏移盖掉了。

原来的自检只核对算出来的量（一顿 0.22 米），所以没发现。新加的 `joltCamRun` 量画面实际用的镜头：
- 修之前：龙撞上之后 0.05 秒，偏移 0 米；
- 修之后：0.24 米（一顿 0.22 加震屏）。

做法：交给主循环的改为 `camView`（演出机位加上偏移）。

### 3. 暂停时镜头会一直抖

震屏原来每帧取一次随机数。暂停时（菜单、失焦）游戏时钟为 0，但画面照常重画；若停在撞上之后 0.4 秒内，镜头会一直抖。

改为按演出时刻取的平滑噪声（每秒约 30 次变向）：同一时刻同一个偏移，暂停时镜头不动，帧率不同抖法也一样。新加的 `pauseShakeRun` 在旧做法上不通过：同一时刻算两次偏移不同。

### 4. 撞地声听不出来

第一版的撞地闷响由 66 赫兹沉到 24 赫兹，能量几乎都在 30 赫兹以下。录像混音里：
- 凤砸入的 20–80 赫兹多了 4 dB；
- 80–2000 赫兹反而比第二十七轮低约 1 dB。

原因有两个：
- 那一段普通音箱放不出来；
- 混音与游戏的总线压缩（阈值 −14 dB、4:1、起音 4 毫秒）按峰值压，低频的大振幅让它压得更深，别的声音一起变小。

改了三处（第五节）：
- 闷响只沉到 34 赫兹、音量降低；
- 加了 80–250 赫兹的「身子」与 1 千赫上下的「啪」，起音不短于压缩的起音；
- 砸入前后音乐让开一下。

### 5. 慢放录像的声音时刻

录像的时钟按游戏时间走。0.5 倍慢放时，声音会落在录像里一半的时刻上。录完把音效、循环声、音乐的时刻都除以倍率（`tools/r27_film.js` 的 `scnSlow`），声音各自按原速放。

### 6. 性能自检把每一帧都当成天空重绘排除了

`perf27Run` 包住了天空的 `refreshEnv`，用来记下哪一帧重绘了环境贴图。自检时 `skyQuiet(true)` 已把它换成空函数，但天空的老问题让它在第一次重绘之后每帧都被调用。结果每一帧都被当成重绘帧，从统计里排除掉，各段算不出数。

改为：只有真的重绘时才排除。第二十七轮报告里的性能数字，各段都是完整的 959 帧，没有受这个问题影响。

## 五、声音

### `inkSlam`（`src/core/audio.js`，合成）

从低到高几层：
- 往下沉的低闷响：正弦 70 → 34 赫兹；
- 墨团砸地的「身子」：正弦 130 → 58 赫兹，软削波带出泛音，低通 520 赫兹；
- 一声湿重的「啪」：粉噪声带通 950、340 赫兹，起音 5 毫秒；一下很短的「溅」：2.4 千赫；
- 墨浪声：粉噪声，低通由 2000 扫到 240 赫兹；
- 8 下溅落的墨点（带通粉噪声）；
- 低沉的余音（褐噪声，低通 200 赫兹）。

`pitch` 越高越轻：凤的音高 1.15。

### 音量与音乐让开

- 凤一声 0.54（0.9 × 0.6），龙一声 0.9；余震四声 `inkHit`，0.5，音高 0.7–0.8；
- 演出音乐：10.42 秒起 0.08 秒内压到 0.7，10.95 秒起 0.5 秒回升。收刀合拢前后原有的让开（13.0–13.55 秒压到 0.4）不变。

### 实测（录像的离线混音，与游戏同一套压缩参数；`tools/r28_audio_check.py`）

听感用 A 计权的短时响度：按人耳对各频率的灵敏度加权，约 46 毫秒一段，取最大值。砸入取 10.45–10.95 秒（凤、龙、第一次余震），收刀清响取 13.13–13.58 秒。

| | 第二十七轮 | 本轮 |
|---|---|---|
| 普通敌人：砸入 / 收刀清响（A 计权） | −23.9 / −18.9 dB | −24.3 / −18.8 dB |
| 收刀比砸入响 | 5.0 dB | 5.5 dB |
| 第三十层：砸入 / 收刀清响 / 差 | −24.1 / −19.2 / 5.0 dB | −24.8 / −19.1 / 5.7 dB |
| 普通敌人的采样峰值：砸入 / 收刀清响 | −7.3 / −5.2 dBFS | −6.0 / −5.4 dBFS |

各频段的能量（普通敌人，dB）：

| 段 | 20–80 赫兹 | 80–250 | 250–2000 | 2000–12000 |
|---|---|---|---|---|
| 凤（10.45–10.70）第二十七轮 → 本轮 | −30.0 → −27.1 | −26.7 → −25.9 | −25.0 → −25.3 | −35.8 → −37.1 |
| 龙（10.69–11.13） | −26.1 → −26.2 | −27.5 → −27.3 | −26.3 → −28.1 | −34.8 → −39.2 |
| 余震（10.83–11.73） | −25.3 → −24.8 | −26.6 → −27.0 | −26.1 → −26.6 | −34.6 → −35.4 |

压缩之前，撞上那一刻合成音与演出音乐的比（混音里的比例）：
- **第二十七轮**：撞击声（`inkHit`）在中频比音乐低约 19 dB（龙），几乎被音乐盖住；
- **本轮**：墨震在中频比让开后的音乐高 1–2 dB，80–250 赫兹高 6–8 dB，20–80 赫兹高 6–9 dB。

结论：
- 墨震成了撞上那一刻的主声音；
- 整体听感响度与第二十七轮相当，多了低频的分量；
- 龙砸入时中高频反而低约 2–4 dB：音乐让开了一些，墨震补上的主要是低频；
- 收刀清响仍是整段最响的一下。

**采样峰值**：两者接近。合成音的噪声每次渲染不同，同一份录像记录重渲七次，相差 ±1.5 dB。调整过程中有几次砸入的采样峰值比收刀高 0–2.1 dB，都来自低频波形，A 计权下收刀仍响 4.5 dB 以上。定稿的两段完整录像（普通敌人、第三十层）里，收刀的采样峰值也最高（慢放片段里没有收刀）。

## 九、没做完 / 限制

- **声音没有实听**：只在录像的离线混音里量过响度与各频段（与游戏同一套压缩参数），没有在不同音箱、耳机上听过。
  - 低频的分量在小音箱上放不出来；那时听到的主要是「身子」「啪」与墨浪声。
  - 龙砸入时的中高频比第二十七轮低约 2–4 dB（音乐让开了一些）。若觉得龙那一下不够亮，可把 `quake.duck.k` 调回 1（不让开）。
- **墨柱是朝向镜头的笔触带**（同第二十七轮的墨带）。演出的机位都是平视或略俯视；从正上方往下看会变窄，演出里没有这样的机位。
- **位置带随机**：余震、喷墨、碎墨、墨柱的落点与倾斜每次略有不同；时刻与数量固定。
- **天空每帧重绘环境贴图**：第十三轮起的老问题，第二十七轮已单独提出，本轮没有改。测性能时同样用 `skyQuiet(true)` 关着。
- **后台标签页的偶发卡顿**：见第六节，与墨震无关的段落里同样出现。在前台、正常帧率下没有专门测过。
