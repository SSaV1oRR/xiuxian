# 第二十四轮报告：通天塔第三十层 · 烬狱剑尊

本轮在现有游戏里做了第三十层的守关 Boss。人物操作、战斗结算（`combat.damage`）、闪身、格挡与弹反、剑诀、凤凰、雷龙、等级与存档都沿用原有的；第三十层有自己的配置、场景与状态，不覆盖第五十层。

全部参数是首轮测试值，集中在 `src/game/boss30Config.js`：

- `BOSS30`：名号、等级、境界、文件、配色；
- `CONFIG30`：气血、场地、判定、弹反、架势、截锋、留锋突刺、选招、伤害、火焰、焚天断界、过场；
- `COMBOS30` / `COMBO_AI`：十套连招与选招权重；
- `SPECIAL30`：截锋反击、留锋突刺；
- `FIRE30`：七种火焰招式里由招式组装的六种（燃刃留痕挂在重刀上，参数在 `CONFIG30.fire.F03`）。

下文的数字都出自页面里按真实输入、出招、结算与特效代码推进的自检（`tools/r24_tests.js`，`runAll()` 一次跑完约 16 秒），录像出自 `tools/r24_film.js`。改动前备份：`backups/xiuxian-r23-20261011-0445.zip`。

## 2. 素材：检查结果、绑定与对应表

### 2.1 剑尊模型（`assets/boss/boss30/soul_of_cinder_-_dark_souls_3_boss_tilt_brush.glb`，只读）

- **来源**：Sketchfab「Soul Of Cinder - Dark Souls 3 Boss Tilt Brush」，作者 vrhuman，CC BY 4.0（写在文件的 `asset.extras` 里）。
- **原状**：25 个物体、12 个网格、28.0 万顶点、25.2 万面，按笔刷材质分组（油画、墨、光、火、纸、荧光笔……）。没有骨骼，没有动作；场景里除了人物，还有地面、大剑与一圈装饰笔画。
- **分出人物**：按连通块（一笔一块）的中心与包围盒聚类，16,990 块里选出人物的 16,137 块（26.5 万顶点）。再分类：
  - 身体 14,516 块（24.1 万顶点）；
  - 手中的黑剑 28 块（412 顶点）；
  - 背后的火焰大剑 1,587 块（不用）；
  - 零散笔画 6 块（不用）。
  
  其余场景笔画另存为 `boss30_props.glb`，摆在场地的悬浮岩岛上。
- **剑**：按顶点求主轴，握点是拳心投到剑轴上的一点。剑长 1.52，握点到剑尖 1.277、到剑首 0.242（模型单位）。放到自己的坐标里（握点为原点、+Y 指剑尖、+X 是刃宽方向），挂在右手骨上。
- **骨架**：取动作包里的 UE5 Manny 骨架（`Idle1_IP.fbx`），按人物比例改骨长，各关节对准人物的肩、肘、腕、拳、胯、膝、踝、颈、头（16 根对准的骨夹角误差都是 0.0°）。
- **权重**：在人物原本的姿势里按笔画到骨胶囊的距离衰减算。披风按颜色单独处理（2,358 顶点），小块笔画整块跟一根骨，每个顶点至多 4 根骨。之后把网格烘回骨架的静止姿势重新绑定（静止姿势误差 0.0）。
- **导出**：只留 25 根变形骨（去掉 63 根）。双面笔画去重：身体 24.1 → 13.7 万顶点，剑 412 → 236。贴图 1024 → 512，纯白的占位图压到 16 像素。动作关键帧精简 14.5 → 4.7 万，量化 + meshopt 压缩。
- **运行时**：整体缩放 0.875（剑尊高 2.1 米）。导出器把所有材质的自发光写成白色、金属度贴图写成纯白，运行时改回：自发光只给火、光两种笔刷，金属度改成半金属的旧铁。

绑定结果（Blender 渲染，正面 / 侧面）：`docs/screenshots/r24_rig_results.jpg`。实际运行中的各个动作：录像 `r24_actions.mp4`。

### 2.2 动作包（`assets/fighting/One Handed Sword Animation V5 FBX`，只读）

- **内容**：IP（原地）与 RM（带根运动）两套 FBX，UE5 Manny 骨架。包括待机三种、拔剑 / 收剑、四向走、跑、四向受击、后闪、前冲、死亡、跳（四段）、Attack1–10（多数分段，带 `_Back` 收招与 `_Complete` 整段）。
- **导入**：游戏用了 48 段，取 RM 版，只留变形骨的转动与骨盆位移，骨盆位移按骨长比例缩放。根骨位移另存一张表（`boss30_anim.json`），运行时乘缩放、按朝向转好，交给控制器限制在场地里，再落到剑尊身上。
- **剑尖轨迹**：逐段量过剑尖与剑柄（剑按拳轴临时挂在右手上），用来挑每一刀的有效段（`r24_analyze_clips.py`）。
- **包里没有直刺**：逐段查过剑身朝前、剑尖在身前、齐胸高的帧，只有零星一两帧。
  - Attack2_Stage3：从身侧送到正前方，剑尖 1.9–2.5 米高，是齐头高的横送；
  - Attack5_Stage1：先是一记向下的斜劈，剑尖落到地面；
  - Attack6_Stage2：横扫。
  
  所以直刺是制作的（§2.4）。

## 3. 场地与流程

- **入口与场地**：
  - 一层楼层传送阵选「第 30 层 · 烬狱剑台」→ 挑战说明 → 进入；落在桥头（0, 29.2）。
  - 剑台半径 18 米，台沿一圈碰撞，玩家限在 17.45 米内，剑尊在 16.4 米内；台心开阔、地面平整。
- **开战**：走上剑台、离台心 16.8 米以内，开演出场；过场里火墙升起、拱门封住。
- **结束**：胜利后火墙落下、拱门打开；失败或放弃后，火墙与拱门在重新挑战之前保持原样。
- **真实的进出（`entryRun`，按界面与按键走一遍）**：

| 步骤 | 实测 |
|---|---|
| 塔内 → 挑战说明 | 面板 `boss30`、有「进入第三十层」 |
| 进入 | 世界 `boss30`、未触发、站在 (0, 29.2)，火墙与拱门开着 |
| 按 W 走上剑台 | 离台心 16.8 米处触发出场（看过的可跳过），空格跳过 → 战斗，火墙与拱门关上，血条出现 |
| 战斗中按退格 | 弹出「放弃挑战」，确认 → 回到桥头、未触发、气血满 |
| 拱门下按 E | 回到一层；剑尊模型、特效、界面都已释放，没有按住的键，镜头不锁 |

## 5. 弹反、一顿、完整收势与架势

- **弹反表（`parryTable`）**：每套的每一击各弹一次，先空跑量出每一击真正碰到玩家的时刻，再在那之前 0.08 秒新按下格挡。
  - 27 / 27 都按招式表：中途的一击一顿，收招的一击完整收势，A05 任一击完整收势。
  - 每次弹反架势 0 → 20。
- **一顿（`hitchRun`）**：A03 第一刀被弹，剑尊的时间轴停住。动作时刻一直停在 0.5、不追帧，之后接着出第二刀。
  - 停的是游戏时间 0.15 秒；弹反本身还有一小段全局顿帧，合计 14 帧。
- **完整收势**：放制作的 `parry_recoil`，一阶段 1.0 秒、二阶段 0.8 秒。
- **架势**：
  - 上限 100；弹反 +20；玩家招式按自带的架势值，没有的轻 3、重 6；持续伤害不加。
  - 6 秒没受压力后每秒衰减 5；两个阶段开始时清零。
- **失衡（`breakRun`）**：
  - 一阶段 2.40 秒、二阶段 2.00 秒；受击 → 单膝跪地 → 起身，结束后架势 0。
  - 崩溃中再打满不重新计时；崩溃中受伤 ×1.25，不出招、不截锋。
  - 在空中（跃起）打满的，落地再崩溃。
- **统一状态**：剑尊的状态只有一个（`B.mode`），失衡、收势、受击、截锋互相不叠加计时。

## 6. 截锋架势（`guardRun`）

- **发动**：
  - 条件：剑尊空闲（不在出招、受击、失衡、收势或过场里）；玩家在身前 3.8 米内、角度 120° 内，没有在出招、0.4 秒内没被打中；冷却 8 秒。剑尊是先摆出架势、等玩家打上来，不读按键、不在同一帧对按键作出反应。
  - 每 0.4 秒判一次，基础概率 0.22（二阶段 0.30）；连续正面普攻时提高到 3.5 倍。
- **过程**：侧身横剑（制作的 `guard`），准备 0.35 秒，窗口 0.18 秒，落空后破绽 0.6 秒。

- **只截什么**：只截真实到达的近战剑击（玩家普攻四式、拔刀斩的刀身，`realMelee`）。凤凰、雷龙、地火、万剑归宗、剑气、持续伤害都不截，也不读按键。

## 9. 焚天断界（`ultRun`、`ultFirstUse`）

- **参数**：蓄力 5.5 秒，冷却 40 秒（从 4 秒恢复结束后才开始计），恢复 4 秒，二阶段开始 12 秒后才可能第一次放。
- **危险区**：以台心为圆心、半径 √0.75 × 18 = 15.588 米（面积为台面的 3/4），蓄力开始时定下，之后不动。
- **四段演出**：
  - 0–1 秒：举剑，地纹与亮边亮出；
  - 1–3 秒：火向剑身汇聚；
  - 3–5 秒：增强，火盆旺火，声音升高；
  - 5–5.5 秒：最终前摇；
  - 5.5 秒爆发。
  
  地面图案、亮边、明暗、声音与屏中倒计时一起表达。

| 情形 | 实测 |
|---|---|
| 选招 | 二阶段第 0 / 6 / 11.9 秒：200 次选招里 0 次是焚天断界；第 12.1 / 20 秒：145 / 154 次（约 75%）；冷却中：0 次 |
| 起跳 → 落到台心 | 1.02 秒；蓄力 5.52 秒（5.5，差一帧）；恢复 4.01 秒；之后冷却 40 秒 |
| 从台心旁 1 米处开始往外跑 | 跑到 17.45 米（台沿），爆发时在区外：没事 |
| 站在区内，爆发前 0.05 秒闪身 | 结果「闪身」，没事 |
| 站在区内不动 / 一直举着格挡 / 爆发前 0.08 秒新按格挡（弹反） | 都被打中（火、致死，气血 160 → 0），经统一的伤害入口倒下 → 失败过场 |
| 蓄力第 2 秒时把架势打满 | 失衡，这一招中断（没有爆发判定），冷却照算（中断后从 40 开始减） |

- **只判一次**：爆发只判定一次（`ultBurst`），之后的余波、地火粒子不再判定。
- **蓄力期间**：剑尊不出别的招，留锋突刺也不触发（剑尊忙）。
- **安全区可达**：玩家用普通的跑就够，不需要任何技能。从最难的位置（台心旁 1 米，剑尊落地后玩家最近只能站这里）跑到亮边以外约 14.6 米，按正常跑速在 5.5 秒内跑到（实测跑到了 17.45 米的台沿）。台面没有墙，剑尊在台心，不挡路。

需求两处写法不一致：第十节「释放后完整恢复 4 秒」，第十四节验收第 10 条「结束后有 2 秒恢复」。这里按 4 秒做（`CONFIG30.ult.recover`，改一个数就能换成 2）。

## 15. 测试中发现、已修好的问题

本轮后半段（临时目录被清空之后）发现并修好的：

1. **临时目录被清空**：绑定与导出的脚本、Blender、Node 依赖都在会话的临时目录里，中途被系统清掉。
   - 恢复：脚本按会话记录里的写入与修改逐条重放，存进 `tools/`；Blender 与 gltf-transform 重新下载、安装。
   - 核对：重跑的结果与之前逐项一致。连通块、分类、剑的量测、骨架对准、权重、去重、贴图、glb 字节数都相同；新旧 glb 的网格、蒙皮、节点逐位相同，55 段动作里只有本轮改过的两段不同。
2. **留锋突刺从来打不中**：原来的突刺取的是 Attack2_Stage3，那是齐头高的横送，冲到身前时剑尖在 2.46 米高，从玩家头顶掠过。逐段量过动作包，没有直刺（§2.2），改为制作的直刺（§2.5）。现在 5 / 8 米的后闪都打中。
3. **运行时的剑尖、握点都不对**：压缩（量化）把剑节点的本地坐标改成了 [-1, 1] 的归一坐标，导出时「握点为原点、+Y 指剑尖」那一套不再成立。结果算出的「剑尖」离剑身 0.85 米，在剑身侧面；「握点」在剑身正中。
   - 修法：载入时按剑的网格求主轴、按右手骨定剑首一端、按导出时量的比例定握点。
   - 修后：握点离手骨 6–7 厘米，剑尖在网格上（2.5 厘米内），握点到剑尖 1.118 米（1.277 × 0.875）。
   - 之前的判定、剑光、火花都按错的那根线算，修后全部重测：十套命中全中（A10 第一刀原来漏判），弹反表 27 / 27（原来 26）。
4. **着色器的高度与剑身坐标不对**：身体的顶点同样被量化（还原的缩放、平移在反绑定矩阵里）。
   - 受影响的效果：出场凝形、击败碎烬、蓄力光点的「高度」按的是归一坐标——凝形在前 40% 的时间里就做完了，胸口光点根本不在身体上。剑刃燃火按剑节点的 y 算，几乎从来不显示。
   - 修法：按绑定姿势求出「量化坐标 → 模型本地（米）」的矩阵交给着色器，剑刃按握点到剑尖的位置算。
   - 修后：凝形、碎烬按 0–2.48 米走，胸口光点在 1.88 米的胸骨上，剑刃燃火显示正常。
5. **F07 炎刃重坠的刀身够不着人**：落地斩原来拼的是「上身重劈 + 下身落地」，骨盆一换，重劈的上身跟着拧开，剑从身后劈到脚边，剑尖最远只到身前 0.33 米。另外 Attack8_Stage1 只有 31 帧，后 0.4 秒停在最后一帧。改为全身放完整版的重劈（Attack8_Stage1_Complete，原速放到收势），剑尖劈到身前 1.9 米。
6. **F07 的火冲击比刀身先到**：原来落地即炸，刀身随后才到，在玩家受击后的无敌里落空。改为落地时亮出火纹、0.45 秒后炸开：刀身先劈下（可弹反），弹完再闪身或走出圈外。
7. **F04 后两道火浪几乎同时到**：准备 0.5 / 1.0 / 0.45 秒，第二、三道起步只隔 0.22 秒，看上去是一道双浪。改为 0.5 / 0.6 / 0.45，起步间隔 1.64 / 0.60 秒。
8. **举剑停顿与帧率有关**：动作时间每帧按「帧开始时」的速度走，跨进停顿的那一帧前半段按原速多走了一截。30 帧时 A10 第二刀间隔短 0.18 秒（0.90 对 1.08）。改为跨区段边界时分段算，三种帧率差在一帧内（§13）。
9. **燃刃留痕只有一块**：剑尖修对之后，重劈的剑尖只在很短的时间里低于 1.0 米。改为低于 1.3 米、每 0.7 米一块，现在一道 2 块。
10. **二阶段地面裂纹烧得发白**：与金白的地面预警抢眼。改为只烧到深红 / 橙，符文的亮度 0.7 → 0.5；预警（金白、带动画的边）一眼能分出来（`docs/screenshots` 的录像联系表）。
11. **跳过失败过场时剑尊停在半路**：改为跳过直接落在玩家身前的收势。
12. **A06 第三击不是突刺**：需求写的是「横斩、回撩、突刺」，原来用的 Attack2_Stage3 是横送。改为制作的直刺 + 1.2 米滑进（受间距修正，不会贴到玩家身上），节奏仍在范围内（0.45 / 0.30, 0.25 / 0.88）。
13. **首通奖励里的「养元丹 ×2」**：第十九轮起养元丹恒为 99，这两颗等于没有，拿掉了。另外两样新物品（烬狱剑印、不灭余烬）原来在行囊里没有名字，补进 `data.js`。
