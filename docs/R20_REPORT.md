# 第二十轮：普攻与拔刀斩的水墨特效、拔刀斩的侧身蓄势

本轮按要求改：
- 一、处理水墨素材：解包 `FX_Ink slash.unitypackage`，取用包里的水墨贴图、两个网格与粒子参数，在现有的 three.js 引擎里重建材质、粒子、动画与播放时序（§1）。
- 二、普攻的水墨刀光：沿剑的真实轨迹铺开，四式各按自己的轨迹；命中处一团墨，空挥只有刀光；取消、换招、受击、力竭时正确收掉（§2）。
- 三、拔刀斩的侧身站姿：蓄势时侧身、沉胯、屈膝、上身前倾，右手握柄、左手扶鞘；常用的背后镜头里看得见剑柄、握柄的手与鞘（§3）。
- 四、蓄力时墨向刀聚：墨点、墨雾、细小光粒沿螺旋收向剑柄与鞘口，蓄得越久越密越快，蓄满后不再增加（§4）。
- 五、拔刀斩出刀：一道月牙墨自左向右扫开，外沿就是这一刀的判定距离，张开就是判定弧（§5）。
- 六、性能与验收（§6、§7）。

另有：录像与截图（§8）、仍有的限制（§9）、文件（§10）、附录：素材包里各预制体的原参数（§11）。

几点约定：
- 改动前的项目备份在 `backups/xiuxian-r19-20261010-0243.zip`。
- 原有素材没有改动。素材包按要求解在原包旁边（同一目录），原 `.unitypackage` 保留未动。
- 下文的数字都是在游戏里按真实的输入、出招、结算与特效代码推进实测的（`tools/r20_ink.js`，见 §10），定稿后在最终代码上重跑过。

## 1. 水墨素材

### 1.1 解包

- 项目的引擎是 three.js（网页），`.unitypackage` 不能直接当网页资源载入，所以先不依赖 Unity 把它解开。
- `tools/r20_unpack_unitypackage.py`
  - `.unitypackage` 是 gzip 的 tar：每个资源一个以 GUID 命名的目录，里面是 `pathname`、`asset`、`asset.meta`，可选 `preview.png`。
  - 逐个读出再写盘（不用 `extractall`）。`pathname` 必须在 `Assets/` 下、不含 `..` 与盘符，否则跳过——包里的路径写不到目标目录以外。
  - 路径含空格（`special effects`、`FX_Ink slash`）：各工具的路径都按参数传入、加引号。
- 解出的位置：`assets/special effects/FX_Ink_slash/FX_Ink slash/`
  - 按包内原有的目录：`Animations/`、`Materials/`、`Mesh/`、`Prefab/`、`Scenes/`、`ShaderForge/`、`Textures/`，各带 Unity 的 `.meta`。
  - 另有 `_previews/`（Unity 生成的缩略图）与 `_package_index.json`（GUID → 路径，解析预制体里的引用时用）。
- 原包 `FX_Ink slash.unitypackage`（2,473,599 字节，2024-03-16）未改动。
- 包里有：
  - 6 个预制体；
  - 19 个材质、20 张贴图、2 个 FBX 网格；
  - 2 段 Animator 动画（与控制器）；
  - 1 个 ShaderForge 着色器（`Blend_DisUV`，溶解）；
  - 1 个演示场景。
- 运行时只载入转换后的 `assets/converted/fx/ink/`（§1.3、§1.4），不读 Unity 的文件。

### 1.2 读出特效参数

- `tools/r20_ink_parse.py` 读预制体与材质（Unity YAML），把每个粒子系统的要点参数摘成 JSON：
  - 层级里的位置与朝向；
  - 寿命、速度、大小、颜色；
  - 发射（每秒数量、定时成批）与形状；
  - 大小、颜色、旋转、速度随寿命的曲线，序列帧，噪声，拖尾；
  - 渲染方式（面片、拉长面片、网格）与材质。
- 材质新旧两种存法都读；内置着色器按编号认出（Additive、Alpha Blended、Premultiply、Mobile VertexLit、Standard）。
- 六个预制体共 121 个粒子系统。`FX_InkSlash_04-3` 一个就有 86 个，是 9 组相同的子发射器。原参数见附录 §11，网页里的取值与出处注在 `combatConfig.js` 的 `INK`。

### 1.3 贴图

`tools/r20_build_ink.py` 把包里的 PNG 做成三张单通道灰度图。图里只存墨的覆盖度，颜色在着色器里给：浓墨 `#09090c`、灰色墨雾 `#55575e`、白光。

| 文件 | 尺寸 | 内容 |
|---|---|---|
| `ink_sprites.png` | 2048 × 1536 | 粒子贴图集（4 × 3 格，每格 512²；小图 256² 一格放四张） |
| `ink_strips.png` | 1280 × 1904 | 带子用的展开长条（u 沿笔画、v 横过笔画） |
| `ink_noise.png` | 512 × 512 | 溶解噪声 |

  - 粒子贴图按原尺寸放；64–128 的几张小图放大到 256 一格。

### 1.5 Unity 的做法在网页里怎么重建

| Unity | 本项目（`src/game/inkFx.js`） |
|---|---|
| 粒子系统：逐个粒子在 CPU 上模拟，各模块（发射、形状、随寿命的速度 / 大小 / 颜色、序列帧、噪声） | 实例化面片池：出生时写一次（位置、速度、大小、寿命、贴图、序列帧），之后的位置、大小、序列帧、淡出、溶解全在着色器里按年龄推算，CPU 每帧不逐个更新 |
| 刀光：一个固定形状的弧形网格绕轴快转，与角色的剑无关 | 带子沿剑的真实轨迹铺开：按动作本身在两帧之间补点（`Cultivator.bladeLocalAt`，每 1/240 秒动作时间一点），帧率低时也是圆弧、与画面上的剑一致；贴展开的墨弧，笔头始终在剑刃上 |
| 序列帧（`ink_all` 六帧在寿命里放完） | 碎开时在六条展开的长条之间交叉淡入，墨弧由浓到枯到碎 |
| ShaderForge 溶解着色器 `Blend_DisUV`，Animator 把 `_Mask_Range` 由 3 推到 0 再推回 3 | 着色器里按噪声阈值溶解（`ink_noise`），阈值随年龄推进；带子、月牙、墨溅、墨花都用 |
| Animator：蓄力预制体的四条弯带子，贴图偏移 0.28–0.32 秒里由 -1 推到 1 | 弯带子着色器的偏移按年龄推进（0.34 秒），墨笔扫向剑柄那一端 |
| 拉长面片（Stretched Billboard） | 着色器里顺着速度方向拉长（墨点、蓄力的墨点与光粒） |
| Legacy Additive / Alpha Blended / Premultiply | 白光用加色混合，墨与墨雾用普通透明混合；都不写深度 |
| 预制体在固定位置播放 | 都绑在实际的位置上：刀光跟剑、命中在剑与身体的接触点、月牙跟人到判定那一刻、蓄力的汇聚点每帧取鞘中那把剑的剑柄与鞘口 |

另做了 Unity 包里没有的：
- 蓄力时「向刀汇聚」：包里的蓄力预制体是一团墨雾、一个墨圈在原地翻涌，加四条弯带子里墨笔扫过，没有向刀收拢的粒子。这一层按要求新做（§4）。
- 刀光侧对镜头时朝镜头补一点宽度：竖劈从背后看不会缩成一条线。

## 2. 普攻的水墨刀光

### 2.1 怎么画

- **出现**：每一式在动作自己的一段时刻里铺带子，把战斗配置里的有效段包在里面。

  | 招式 | 带子铺开（动作时刻，秒） | 有效段 | 内沿在剑身上 | 外沿伸出剑尖 | 碎开 |
  |---|---|---|---|---|---|
  | 斜斩 | 0.16–0.285 | 0.185–0.255 | 剑身 45% 处 | 0.3 米 | 0.34 秒 |
  | 反手横斩 | 0.135–0.27 | 0.16–0.235 | 45% | 0.3 米 | 0.34 秒 |
  | 突刺 | 0.2–0.31 | 0.225–0.3 | 剑尖划过处一笔墨痕 | 0.4 米 | 0.3 秒 |
  | 重劈 | 0.37–0.5 | 0.4–0.47 | 38% | 0.42 米 | 0.45 秒 |

- **样子**：贴展开的 `ink_all` 墨弧。笔头（最浓处）在剑刃上，枯笔的尾巴拖在后面；外沿一线白光只跟着剑尖刚扫过的一小段（0.07 秒）。
- **消散**：铺完停 0.02–0.04 秒，然后六帧依次碎开，同时按噪声溶解、淡出。Unity 里这一层寿命 0.5 秒，这里缩到 0.3–0.45 秒，免得挡住人和敌人。墨的浓度 0.9，不全遮死。
- **墨点**：收剑时沿刀势甩出 6–12 个墨点（`circle00_sp2`，顺着来路拉长），1–2 团灰色墨雾。Unity 是每秒 300–2000 个、一次几十个，这里只留少量。
- **突刺**：不铺扫过的面。剑尖划过处一笔朝镜头的墨痕（`ink_05-all` 后五帧）；刺到头（0.245 秒）剑尖处一圈墨环朝刺的方向张开，从背后也看得见。
- **命中**：在实际的接触点（剑身与对方身体胶囊最近处）放：
  - 一团墨溅（`ink_03_all` 四帧，寿命 0.55 秒、前一半放完序列帧；Unity 是 0.6 秒、前 44%）；
  - 一朵受击墨花（`Hit by flash-1`，0.32 秒）；
  - 6–10 个墨点；
  - 一点白光与一道细白光（0.13 / 0.09 秒）。
  - 重劈放大 1.35 倍。被格挡、免疫时不放；空挥只有刀光。
- 守关龙君身上：龙君自己的受击火星与声音照旧，另在它被砍中的那段身体上补一团墨。
- 这几招不再拖第十七轮青色的剑光。水墨素材没载入时，照旧用第十七轮的拖尾与火星。

### 2.2 方向与位置（实测，`combo`）

按住左键一轮，身前一只魔修。带子铺完时记下扫过的方向（人物坐标：右、上、前，米）与扫过的面的倾角（面的法线离竖直多少度：0 是平扫，90 是竖劈）：

| 招式 | 起点 → 终点 | 倾角 | 外沿走过 | 带子的头与剑的偏差 |
|---|---|---|---|---|
| 斜斩 | 右上 (0.43, 2.74, 0.35) → 左下 (-1.00, 0.10, 0.53) | 56° | 4.06 米 | 0 厘米（20 帧） |
| 反手横斩 | 左 (-1.29, 1.79, -0.07) → 右 (1.56, 1.65, 0.16) | 11° | 4.85 米 | 0 厘米（22 帧） |
| 突刺 | 身前 1.56 米 → 2.10 米，离地 1.18 米 | 墨痕 | 1.23 米 | 0 厘米（9 帧） |
| 重劈 | 头顶 (0.07, 3.14, -0.16) → 身前地面 (0.02, 0.14, 1.74) | 85° | 4.30 米 | 0 厘米（12 帧） |

- 斜斩是倾斜的墨弧，反手横斩是横向的墨弧，重劈是竖着的一笔，突刺是一笔直的墨痕——与动作一致。
- 带子的头每一帧都在剑上（偏差 0）。
- 有目标：6 刀命中 6 次，6 团墨。空挥（没有目标）：7 刀，0 团墨。
- 连续按住时同时最多 3 条带子；松手 1.7 秒后带子、墨粒子、月牙全部归零。

### 2.3 取消、换招、受击、力竭（实测，`cancels`）

| 情形 | 带子 | 收掉用时 |
|---|---|---|
| 斜斩前摇里闪身（有效段之前） | 还没开始铺，直接作废；墨粒子 0 | — |
| 斜斩收势里闪身 | 已铺好的照常碎开 | 0.18 秒 |
| 斜斩收势里接剑诀（0.02 秒换招） | 照常碎开 | 0.15 秒 |
| 重劈出手中被击退 | 立刻停止延伸（17 个采样点不再增加），很快碎开 | 0.18 秒 |
| 拔刀斩扫到一半被击退 | 刀光带子与月牙都很快碎开，不放墨溅 | 0.18 秒 |
| 斜斩出手中力竭 | 招式归位，带子碎开 | 0.17 秒 |

## 3. 拔刀斩的侧身站姿

### 3.1 原来的问题

第十九轮的蓄势几乎正对前方：骨盆 10°、两肩 -18°，鞘平压着朝正后方。常用的背后镜头里，剑柄与握柄的右手都被身体挡住（剑柄 0%、右手 13%），鞘朝着镜头、缩成一小段。

### 3.2 做法

- 项目的动作库（Quaternius UAL2）里没有拔刀的侧身架势，所以仍在第十九轮自编的四段动作（纳刀、蓄势、蓄势缓步、出刀）上改：只改姿势的关键帧，由姿势解算（手臂 IK、脚踩地）出动作，段与段之间照旧淡入淡出。
  - 改在 `cultivatorClips.js` 的 `IAI` / `IAI_IN` / `IAI_ENTER` / `IAI_WALK` 与出刀开头的几帧。
- **蓄势**：
  - 骨盆转 66°、两肩连线转 84°，右肩、右脚在前，胸口朝左。
  - 骨盆离地 86 厘米（平常的战斗待机 95 厘米），上身前倾 19°，两膝弯 48° / 73°（后 / 前）。
  - 右手握在鞘中那把剑的剑柄上，左手在鞘口往后约 15 厘米处扶着鞘。头看向前方。
  - 姿势解算加了右肩胛前送（`shR`），右手够得着侧过去的剑柄。
- **鞘的两个位置**：
  - 蓄势时鞘斜着从左胯伸到身后右侧，剑柄露在身体左侧（`IAI_SHEATH_HOLD`）。
  - 出刀时鞘转到抽剑的轴上（`IAI_SHEATH`）。
  - 关键帧里新加 `sh`（0 蓄势的位置、1 出刀的位置），动作里记下；运行时 `Cultivator.applySheath(…, sp)` 在两个位置之间转。
- **进出**：
  - 纳刀（0.3 秒）：前 0.18 秒骨盆只转 26–30°、鞘在出刀的位置，剑顺着鞘的轴推回鞘中；之后转到侧身，鞘转到蓄势的位置。
  - 出刀的前 0.045 秒：骨盆由侧身回拧，左手把鞘由蓄势的位置转到出刀的位置，右手一直握着剑柄。
  - 0.03 秒把鞘中的剑换成手中的剑（两把剑相差 0.2 厘米、0°），出刀这一段改按每秒 60 帧取样，由蓄势出刀的淡入改为 0.03 秒。
  - 按本轮的量法（取动作在那一刻的实际采样），第十九轮在 0.045 秒换手，那一帧两把剑相差 13.5 厘米。动作按每秒 30 帧取样，右手已抽出约 10 厘米。
- **朝向不变**：侧身只在姿势里，人物的朝向、出刀的瞄准、判定都按原来的规则。实测出刀那一刻月牙的朝向与人物朝向差 0°，身前的魔修照常挨刀（§5.2）。

## 4. 蓄力时墨向刀聚

### 4.1 怎么画

- **汇聚点**：每帧取鞘中那把剑的实际位置——剑柄（握持处往柄尾 8 厘米）与鞘口（护手前 7 厘米），所以跟着人、手、鞘走（缓步、闪身也一样）。
- **三种粒子**，每秒生几颗（刚开始 → 蓄满，蓄满后不再加）：
  - 浓墨点：14 → 40；
  - 灰色墨雾：2 → 5；
  - 细小光粒：8 → 22（加色）。
  - 另有贴着剑柄、鞘口打转的一小团墨雾：2.5 → 5。
  - 「流畅」画质减半。
- **轨迹**：从身边 0.9–1.6 米、上下 -0.6 至 +0.9 米处，沿螺旋（0.3 → 0.75 圈）收向剑柄或鞘口。
  - 收到的时间由 0.95 秒缩到 0.55 秒（越蓄越快）。
  - 越近越小，到了即没。墨点、光粒顺着来路拉长，看得出是「被吸进去」。
- **弯带子**（`Ink_Plane001` + `ink_05`，包里蓄力预制体的做法）：每隔 1.2 → 0.5 秒一笔墨顺着弯带子扫进剑柄（0.34 秒）；每过一档（共三档）三条一齐扫进（蓄满那一档四条）、剑柄处一闪。
- **刀周围**：鞘口一道细亮边（`lb_20f_r`），亮度随蓄力由 0.15 升到 1.0；蓄满后每 0.55 秒一闪。整个人不发光。
- **蓄满**：脚下一圈墨（`ink_06`，一次），之后粒子数不再增加。
- **停下**：
  - 取消（举剑格挡、失焦、开界面）、受击打断、力竭：那一刻起不再生，已有的原地散开（0.28 秒）。
  - 出刀：不再生，0.12 秒收掉。
  - 鞘口亮边随之熄掉。

## 5. 拔刀斩出刀

### 5.1 怎么画

- **出鞘的那一刻**（动作 0.14 秒，剑身离开鞘口）放出月牙：包里的月牙网格（`Eric_Cylinder002`）平放在身周，离地 1.05 米，竖向压扁。
  - 外沿半径 = 这一刀的判定距离（3.92–4.8 米，按蓄力）；张开 = 判定弧 200°。
  - 0.14–0.205 秒自左向右扫开（判定在 0.2 秒，那一帧已扫开 98%）。
  - 判定之前跟着人走——判定按那一刻人的位置、朝向算。
- **样子**：墨色主体；扫开的前沿一道白光（`ring02_fire_03`，亮度 0.55 → 1.0 按蓄力）与一线白边。
  - 向外飞散的墨点 10 → 26、弧上墨溅 2 → 5、墨雾 2 → 4（按蓄力）。
  - 剑上另有一条刀光带子（0.135–0.33 秒，伸出剑尖 0.35 → 0.6 米）。
- **之后**：停 0.06 秒，六帧碎开、溶解、淡出（0.55 → 0.85 秒，按蓄力）。蓄力的墨 0.12 秒收掉，鞘口亮边熄掉。
- **剑气**（蓄过 3 秒）：同一个月牙网格缩到剑气的半径，墨色、前沿白光，随剑气飞，沿途甩墨点，消散处一团墨溅。第十九轮是金色。
- 前冲残影的颜色由青、金改为淡墨灰。
- 出刀比普攻强：月牙铺满 3.9–4.8 米、200° 的扇环；普攻的刀光只是剑身外半截加剑尖外 0.3–0.42 米的一条带子。墨点、墨溅也多一倍以上。

### 5.2 与判定对照（实测，`release`、`rangeCheck`）

| 按住 | 蓄力比例 | 判定距离 | 月牙外沿 / 内沿 | 张开 / 判定弧 | 判定那一刻月牙圆心离人 / 朝向差 |
|---|---|---|---|---|---|
| 0.2 秒 | 0.04 | 3.92 米 | 3.92 / 2.43 米 | 200° / 200° | 0 米 / 0° |
| 2.5 秒 | 0.5 | 4.29 米 | 4.29 / 2.66 米 | 200° / 200° | 0 米 / 0° |
| 5.2 秒 | 1.0 | 4.80 米 | 4.80 / 2.97 米 | 200° / 200° | 0 米 / 0° |

判定距离里外各摆一只魔修。距离从判定那一刻人的位置量，判定是「距离 ≤ 判定距离 + 魔修半径 0.45 米」：

| 按住 | 判定那一刻前冲了 | 里面那只（距离） | 外面那只（距离） |
|---|---|---|---|
| 5.2 秒 | 1.69 米 | 4.95 米：挨刀（也挨剑气） | 5.68 米：不挨刀，挨剑气（剑气飞得比判定远） |
| 0.2 秒 | 0.80 米 | 4.07 米：挨刀 | 4.81 米：不挨（没有剑气） |

身体碰到墨痕外沿的就挨刀，墨痕外面的不挨——特效的范围就是判定的范围。

## 9. 仍有的限制

- **出刀时剑身斜穿鞘口**：0.083–0.133 秒剑身离鞘轴 1.2–5.6 厘米（第十九轮最多 4.4 厘米）。鞘的内径约 2 厘米，所以有一两帧剑身斜着穿过鞘壁。0.133 秒还有约 20 厘米在鞘里（第十九轮 22 厘米），下一帧转出鞘口。
- **纳刀时右手够剑柄**：第 0.13 秒差 12 厘米够不到（同一量法第十九轮 20 厘米），右手是追着剑柄过去的。
- **握点**：蓄势时右手握点离剑柄 1.1–1.3 厘米（第十九轮 0.2 厘米），看得出来时是握在柄上偏一点。
- **鞘与长袍**：鞘把下摆顶开，没有布料模拟。鞘离身体（不含衣服）最近 1.3 厘米，不穿。
- **侧身的代价**：两肩转了 84°，从右侧、右后看剑柄与右手被身体挡住（0%）；从左前看鞘只露 34%（第十九轮 50%）。
- **蓄势的脚**：
  - 纳刀最后 0.07 秒两脚各挪 5–6 毫米（合计 1.2 厘米，第十九轮 0.1 厘米），是姿势由「入鞘」转到侧身那几帧的插值。试过纳刀也按每秒 60 帧取样，反而到 3.3 厘米，没有采用。
  - 轻点 Z（纳刀 0.18 秒就转出刀）时，纳刀这一段两脚贴地挪 5 厘米、单帧最多 1 厘米（入势没站稳就淡入出刀）。
- **出刀前冲时后脚被拖着走**：第十九轮就有，本轮略小（§7）。
- **寻常受击打断不了蓄力**（第十七轮以来的老问题，本轮没改）：
  - `combat.damage` 的 `react` 默认值是 `null`：魔修的爪与剑、演武场对手的剑、弹体打中玩家时都不演受击，所以不会打断蓄势。第五十层龙君的招式（它自己指定了受击）、击退、掀翻会打断。
  - 水墨部分对任何打断都正确（强制受击、魔将震地都实测过，§4.2）。
  - 改这个默认值会改变全部战斗的手感，留给另一次单独修。
- **Unity 里有、这里没有或换了做法的**：
  - 软粒子（按深度淡化）没有做：墨雾贴近地面、墙面时边缘是硬的。墨雾很淡、寿命短，不明显。
  - 04-3 带重力、会落地的碎石块（`stone02`）没有移植。
  - 04-3 溶解的墨环（`ink_ring01` + `Blend_DisUV` + Animator）没有原样搬：溶解做在带子、月牙、墨溅的着色器里，墨环改用 `ink_06`。

  - Unity 各粒子的随机起始旋转、大小范围等，按网页的写法简化成每种一两个随机范围。
